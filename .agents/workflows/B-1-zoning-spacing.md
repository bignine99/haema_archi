### SKILL Z1 · AreaSync — 연면적 정합성 자동 검증 엔진

**목적:** 목표 연면적, 법정 한도, 입력 합계값 간의 정합성을 실시간으로 검증하고 오류를 자동 감지

**현재 문제:**
- 목표 연면적 13,157 sqm 대비 현행 입력 합계 11,130 sqm으로 2,027 sqm 미반영
- 용적률 산정 기준 연면적과 실제 계획 연면적의 정의 혼용
- 지하층 면적의 용적률 산입 여부 자동 판단 로직 부재

**구현 방향:**
[연면적 정합성 실시간 검증 모델]

검증 항목 1 — 용적률 산입 면적 구분

용적률 산입 면적: 지상층 전용 + 공용 (지하층 제외)
용적률 미산입 면적: 지하층 전체, 발코니, 옥탑 등
자동 분류 후 용적률 재산정
검증 항목 2 — 면적 삼각 정합성
목표 연면적 (13,157 sqm)
= 현재 입력 합계 (11,130 sqm)

잔여 배분 가능 면적 (2,027 sqm)
오차 허용 범위 (목표 대비 ±2% = ±263 sqm)
검증 항목 3 — 층별 면적 합산 자동화
각 실 면적 합계 = 층 소계 자동 검증
층 소계 합계 = 전체 합계 자동 검증
전체 합계 = 용적률 산입 면적 자동 분류

**추가 출력물:**
- 실시간 면적 정합성 신호등 (정합 / 경고 / 오류 3단계)
- 잔여 면적 배분 가능 공간 목록 자동 제안
- 용적률 산입/미산입 면적 자동 분류표
- 법정 한도 대비 여유율 퍼센트 표시

### SKILL Z2 · RoomCode — 실별 구분 태그 다층화 엔진

**목적:** 단일 '필수' 태그를 다층화하여 실별 법적 근거, 우선순위, 조정 가능성을 자동으로 분류

**현재 문제:**
- 전 항목 '필수' 태그 단일 적용으로 선택/권장 실과의 구분 불가
- 법정 기준 근거 법규 미표시
- 면적 조정 가능 범위 정보 부재

**구현 방향:**
[실별 구분 태그 4단계 체계]

태그 1 — 법정필수 (Legal Required)
근거: 관련 법규 조항 자동 태깅
예시: 장애인 주차 구역 (장애인등편의법 제8조)
비상 계단실 (건축법 제49조)
면적 조정: 법정 최소값 이하 불가

태그 2 — 사업필수 (Project Required)
근거: 과업지시서 명시 항목
예시: 교장실, 행정실, 교무실
면적 조정: 과업지시서 기준 ±10% 허용

태그 3 — 권장 (Recommended)
근거: 학교시설 설계기준 권장 항목
예시: 교사 휴게실, 학부모 대기실
면적 조정: 전체 연면적 한도 내 자유 조정

태그 4 — 선택 (Optional)
근거: 설계자/발주처 선택 사항
예시: 커뮤니티 라운지, 옥상 정원
면적 조정: 잔여 면적 내 자유 배분

**추가 출력물:**
- 태그별 실 목록 자동 분류표
- 법정필수 항목 누락 시 경고 알림
- 태그별 면적 합계 및 전체 대비 비율
- 법정 근거 조항 원문 링크 자동 연동

### SKILL Z3 · LegalRoom — 실별 법정 면적 기준 자동 검토 엔진

**목적:** 각 실의 입력 면적을 관련 법규의 법정 최소/최대 기준과 자동으로 대조하여 적합성 검증

**현재 문제:**
- 실별 법정 면적 기준 표시 없음
- 입력 면적의 법규 적합성 수동 확인 필요
- 특수학교 특화 기준 (학생 1인당 면적 등) 미반영

**구현 방향:**
[실별 법정 면적 기준 자동 대조 모델]

검토 기준 데이터베이스:

학교시설사업 촉진법 시행규칙 (교실 면적)

장애인등편의법 (장애인 주차, 화장실 규격)
소방시설법 (소방 설비실 최소 면적)
주차장법 시행령 (주차 구획 규격)
출력 형식:

장애인 주차 | 50 sqm | 주차대수 2% 이상 | - | 검토필요
일반 교실 | - | 학생 1인당 4 sqm 이상 | - | -

특수학교 특화 기준 자동 적용:

교실: 학생 1인당 최소 4 sqm (학교시설사업촉진법)
치료실: 용도별 최소 면적 기준 (작업치료/물리치료 구분)
특수 화장실: 개호 공간 포함 최소 규격 자동 산정

**추가 출력물:**
- 법정 기준 미달 항목 자동 강조 표시 (빨간색 경고)
- 법정 기준 초과 여유 면적 표시 (조정 가능 범위 안내)
- 특수학교 학생 수 입력 시 1인당 면적 자동 역산
- 법정 기준 근거 조항 원문 팝업 연동

**구현 방향:**
[층별 기능 균형 평가 매트릭스]

평가 항목 1 — 수직 동선 부하 지수
이동 취약 사용자(휠체어, 유치부 등)의 주 활동층 위치

### SKILL Z5 · SpecialZone — 특수학교 특화 조닝 검증 엔진

**목적:** 특수학교 사용자의 특성을 반영한 조닝 계획의 적합성을 자동으로 검증하고 개선 방향을 제안

**현재 문제:**
- 일반 교육연구시설 기준으로 조닝 구성 (특수학교 특화 기준 미적용)
- 생애주기별 수직 조닝 원칙과 실제 배치의 정합성 검증 로직 부재
- 치료실, 특수 화장실 등 특화 공간의 배치 적정성 평가 없음

### SKILL Z6 · AreaDash — Engineering Analytics Dashboard 고도화

**[기존 차트 개선]**

소규모 실 확대 보기 기능 추가

현재: 단순 층별 면적 막대 차트

현재: 층별 코어 비율 꺾은선 단순 표시

예시: B1F→1F 급락 = 지하 설비 공간 특성 자동 설명
Global Net/Gross Balance 개선:

현재: 전체 공용/전용 도넛 차트
개선: 법정필수/사업필수/권장/선택 태그별 면적 4분할 도넛 추가

드래그로 배분 조정 시 실시간 재산정

### SKILL Z8 · DocExport — 설계 산출물 자동 출력 엔진

- 발주처 보고용 요약 자료 자동 생성 기능 부재

**구현 방향:**
[출력 형식별 자동 변환 체계]

출력 형식 1 — 인허가 제출용 시설면적표
형식: 건축법 시행규칙 별지 제1호 서식 호환
내용: 층별 용도, 전용/공용/합계 면적

출력 형식 2 — 발주처 보고용 요약 자료
형식: A3 1장 요약 (설계개요 + 층별 소계 + 대시보드 핵심 차트)
포함 내용: 법정 한도 대비 현황, 특수학교 특화 검증 결과

출력 형식 3 — BIM 연동 스페이스 리스트
형식: JSON / IFC 메타데이터 호환
내용: 실명, 층, 전용/공용 면적, 태그, 법정 기준값

출력 형식 4 — 면적표 Excel 파일
형식: xlsx (층별 시트 구분)
포함 내용: 전체 실 목록, 면적, 태그, 법정 기준 대비 적합 여부

**추가 출력물:**
- 출력 형식 선택 드롭다운 메뉴
