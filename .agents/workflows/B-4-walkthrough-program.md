## 2. 현행 시스템 문제점 분석

### 2-1. 평면 배치 정보 문제

| 문제 항목 | 현황 | 영향 |
|----------|------|------|
| 2F/3F/4F 탭 내용 미표시 | 1F만 평면 표시, 상층부 내용 불명 | 층별 동선 연속성 검토 불가 |
| 실별 면적 일부 미표시 | 외부 놀이마당·학교 숲·보안관실 면적 없음 | 면적 정합성 검증 불완전 |
| HUB 코어 규격 미상세 | "66인승 EV" 언급만 있고 코어 면적/규격 미표시 | 코어 계획 검증 불가 |
| Welcome Street 운영 방안 미상세 | "운영 표본" 표시만 있음 | 실제 운영 계획 연동 불가 |

### 2-2. 동선 분석 깊이 문제

| 문제 항목 | 현황 | 영향 |
|----------|------|------|

| -18% 경로 단축 근거 미표시 | 수치만 표시 | 기준 배치 대비 개선 경로 불명확 |
| 비상차량 회차 동선 검증 없음 | 레이어 표시만 있음 | 실제 소방차 진입·회차 가능 여부 미검증 |
| 보차분리 완전성 검증 없음 | 동선 구분 표시만 있음 | 교차 구간 식별 및 위험도 평가 없음 |

| 문제 항목 | 현황 | 영향 |

### SKILL C1 · FloorNav — 층별 동선 연속성 분석 엔진

**목적:** 현행 1F만 표시된 평면을 2F·3F·4F까지 확장하고 층 간 동선 연속성을 자동 분석

**현재 문제:**
- 2F/3F/4F 탭이 존재하나 내용 미표시
- 층별 수직 동선 코어(EV·계단)의 위치 정합성 검증 없음
- 층별 Learning Loop·Care Loop의 연속성 분석 없음

**구현 방향:**
[층별 동선 연속성 분석 모델]

층별 자동 생성 항목:

층별 조닝 데이터 연동 → 각 층 주요 실 자동 배치
수직 코어(EV·계단·경사로) 위치 고정 후 층별 동선 자동 생성
층별 Double Loop (Learning Loop·Care Loop) 자동 추적
연속성 검증 항목:
수직 코어 정합성:

전 층 동일 위치 코어 유지 여부 자동 확인
HUB(66인승 EV 코어) 전 층 연속 배치 검증
층별 Loop 연속성:

Learning Loop: 층별 학습 존 연결 경로 연속 여부
Care Loop: 층별 치료 존 연결 경로 연속 여부
루프 단절 구간 자동 감지 및 경고
층별 BF 동선 연속성:

1F 주출입구 BF 동선 → 상층부 BF 동선 연결 검증
각 층 BF 동선 커버리지 산출 (목표: 전 층 100%)
출력 형식:
층 | Loop 연속성 | 코어 정합성 | BF 커버리지 | 종합 판정
1F | 완성 | 적합 | 100% | Optimal
2F | - | - | - | 미생성
3F | - | - | - | 미생성
4F | - | - | - | 미생성

**추가 출력물:**
- 전 층 동선 평면도 자동 생성 (층별 탭 완성)
- 층별 동선 연속성 3D 수직 다이어그램
- 코어 위치 정합성 경고 자동 발생
- 층별 Loop 연속성 체크리스트 PDF 출력

### SKILL C2 · CircConflict — 동선 충돌 자동 감지 엔진

**목적:** 차량·보행·비상·BF 동선 레이어 간의 교차 및 충돌 구간을 자동으로 감지하고 위험도를 평가

**현재 문제:**
- 동선 레이어 시각화만 제공, 충돌 구간 자동 감지 없음
- 보차분리 완전성 검증 없음
- 비상차량 동선과 보행 동선 교차 위험 구간 미식별

**구현 방향:**
[동선 충돌 자동 감지 모델]

충돌 유형 분류:
유형 1 — 차량·보행 교차 (Critical)
: 차량 진입로와 BF 보행 동선 교차점
: Swept Path(R≥12m) 반경 내 보행 동선 침입 여부
: 드롭오프 구간 보행자 대기 공간 차량 침입 여부

유형 2 — 비상차량·일반차량 충돌 (High)
: 소방차 진입 경로와 일반 차량 주차 구역 중복 여부
: 비상 회차 반경(R≥12m) 내 장애물 존재 여부
: 소방활동 공지 확보 여부 (건축법 시행령 제40조)

유형 3 — BF 동선·일반 동선 혼재 (Warning)
: BF 전용 경사로 구간 일반 보행 동선 혼재 여부
: 휠체어 회전반경(1.4m×1.4m) 내 장애물 여부

유형 4 — 학생·외부인 동선 혼재 (Warning)
: 지역사회 개방 구역(Welcome Street)과
학생 전용 구역 간 경계 명확성
: 보안관실 CCTV 커버리지 사각지대 여부

감지 결과 형식:
충돌 유형 | 위치 | 위험도 | 개선 방향
차량·보행 교차 | 주출입구 남측 | Critical | 보행 신호 등 또는 물리적 분리 필요
비상차량 충돌 | 주차 구역 북측 | High | 소방 전용 진입로 1.5m 이격 확보
BF 혼재 | Drop-off 전면 | Warning | BF 전용 유도 블록 연속 설치

**추가 출력물:**
- 동선 충돌 히트맵 (위험도 3단계 색상 표시)
- 충돌 유형별 개선 방향 자동 생성
- 보차분리 완전성 지수 자동 산출 (목표: 100%)
- 소방차 Swept Path 시뮬레이션 자동 실행
