### SKILL D1 · MasterScore — 마스터플랜 정량 지표 자동 산출 엔진

**목적:** Weaving School 마스터플랜의 핵심 지표(VSI Score, 생태 유입률 등)의 산출 근거를 정량화하고 3대 전략축 실현 지수를 자동 생성

**현재 문제:**
- VSI Score +42%, 생태 유입률 16.7% 수치의 산출 근거 미제시
- 3대 전략축(We-LIVING/We-LINKING/We-LEARNING)의 실현 지표 없음
- Policy Alignment 정책 충족 근거 자동 생성 없음

**구현 방향:**
[마스터플랜 정량 지표 자동 산출 모델]

VSI Score (시각적 개방감 지수) 산출:
정의: 대지 경계선 내 시각적 개방 면적 비율
(건축물 외벽 불투명 면적 대비 투명·개방 면적)
산출 방법:

1층 전면부 투명 유리 면적 / 전체 외벽 면적 × 100
공개공지 면적 / 대지면적 × 100
두 지표 가중 합산 → VSI Score
현행 +42% 근거:
기준 배치(불투명 외벽 중심) 대비 개방형 외벽 전환 효과
공개공지 법정 기준(141.57 sqm) 대비 계획값 비율
생태 유입률 산출:
정의: 대지면적 대비 생태 면적(녹지+수공간+생태 학습 정원) 비율
산출: (옥상 정원 + 외부 학교 숲 + 생태 학습 정원) / 대지면적
현행 16.7% = (250 + X + 500) sqm / 10,623 sqm

3대 전략축 실현 지수 자동 산출:
We-LIVING 지수:

지역 개방 공간 비율: 계획값 / 목표값
NIMBY 극복 지표: 지역사회 동의율 98% 연동
Zone B 운영 가능 면적 / 전체 면적
We-LINKING 지수:

BF 동선 커버리지: 전 층 BF 접근 가능 면적 비율
수직 동선 연속성: 1F~4F 코어 연결 완성도
지역 보행 동선 연계 접점 수
We-LEARNING 지수:

생애주기별 특화 공간 완성도: 4단계 클러스터 충족률
가변 학습 공간 비율: 전체 학습 면적 대비 모듈화 비율
직업 교육 연계 공간(Job Street) 완성도
Policy Alignment 자동 검증:
제6차 특수교육 발전계획 항목별 충족 근거:
항목 1: 학생 맞춤형 특수교육환경 고도화
→ 4단계 메디컬 재활 클러스터 구현 여부 + 실별 환경 지표 충족 여부

항목 2: 지역사회 상호작용 및 통합교육 거점
→ Zone B 지역 개방 면적 + Welcome Street 동선 분리 완성도

항목 3: 무장애(BF) 디지털 기반 스마트 안심학교
→ BF 최우수 등급 충족 + IoT 시스템 연동 여부
