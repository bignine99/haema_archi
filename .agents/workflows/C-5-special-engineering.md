# 특수 엔지니어링 검토
### Special Engineering | 기본설계 단계
#### 음향 계획 · 스마트 빌딩 · 디지털 엔지니어링 & BIM

---

## 📌 Description

기본설계 단계의 특수 엔지니어링은 일반 MEP 분야를 넘어
건축물의 고품질 사용 환경과 스마트 운영 체계를 구현하기 위한
음향 계획, 스마트 빌딩 시스템, 디지털 엔지니어링 및 BIM 기반
설계 방법론을 통합적으로 계획하는 분야입니다.

각 분야는 독립적으로 계획되나 BIM을 중심으로 상호 연계되며,
설계 품질 향상과 시공·운영 효율화를 동시에 달성하는 것을 목표로 합니다.

## 📋 Contents

### 1. 음향 계획 (Acoustic Planning)

#### 1-1. 음향 계획 적용 대상 및 목표

| 공간 유형 | 음향 목표 | 주요 검토 항목 |
|----------|----------|--------------|
| 공연장·콘서트홀 | 풍부한 잔향, 명료도 확보 | RT60, 초기감쇠시간(EDT) |
| 강당·다목적홀 | 명료도·확산성 균형 | RT60, STI, 음압 분포 |
| 회의실·강의실 | 높은 명료도, 짧은 잔향 | RT60, STI, 배경소음 |
| 녹음·방송 스튜디오 | 무반향·고차음 | NRC, STC, RT60 |
| 사무실·업무공간 | 프라이버시, 배경소음 제어 | NC 곡선, 음성프라이버시 |
| 호텔 객실 | 외부 소음 차단 | STC, 층간소음, NC-30 |

#### 1-2. 실내 음향 설계

**잔향시간 (RT60) 목표값**

| 공간 용도 | 권장 RT60 | 비고 |
|----------|----------|------|
| 오케스트라 공연장 | 1.8~2.2초 | 500Hz 기준 |
| 오페라·뮤지컬 | 1.4~1.8초 | |
| 강당·다목적홀 | 1.0~1.4초 | |
| 회의실 | 0.4~0.6초 | |
| 강의실·교실 | 0.5~0.8초 | |
| 녹음 스튜디오 | 0.2~0.4초 | |
| 사무실 | 0.4~0.6초 | |

**음향 설계 요소**
흡음 계획
├── 흡음재 종류: 다공질(유리면·암면), 판진동형, 공명형
├── 흡음계수(α): 재료별 주파수 특성 검토
└── NRC (잡음저감계수): 흡음 성능 종합 지표

반사 계획
├── 초기반사음 활용: 음향 에너지 균일 분배
├── 반사판 형태: 평면·곡면·확산면 비교 검토
└── ITDG (초기시간지연간격): 20ms 이하 권장

확산 계획
├── 확산체(Diffuser): QRD, MLS 타입
└── 불규칙 요철 마감: 음 에너지 균일 확산


#### 1-3. 소음·진동 차단 계획

**층간소음 기준 (공동주택 품질검사 기준)**

| 소음 종류 | 기준값 | 비고 |
|----------|--------|------|
| 경량충격음 | 58dB 이하 | 슬리퍼, 의자 끄는 소리 |
| 중량충격음 | 50dB 이하 | 어린이 뛰는 소리 |
| 공기전달음 | STC 50 이상 | 벽·바닥 차음 성능 |

**기계실·설비 소음 대책**
소음원 제어
├── 저소음 기기 선정 (설비 사양서에 소음 기준 명시)
├── 방진 마운트: 기기 하부 스프링·패드 설치
└── 플렉시블 조인트: 배관·덕트 진동 전달 차단

전파 경로 차단
├── 방음벽·차음재: 기계실 벽체 STC 55 이상
├── 이중벽 구조: 기계실 인접 거실 측
└── 관통부 처리: 배관·덕트 관통 시 방진 슬리브

수음부 대책
├── 흡음 천장·벽 마감
└── 창호 차음 성능 강화 (삼중 유리 등)


**외부 소음 차단 계획**

| 외부 소음원 | 차단 방법 | 기준 |
|-----------|----------|------|
| 도로·철도 소음 | 방음벽, 고차음 창호 | 실내 NC-35 이하 |
| 항공기 소음 | 중량 외벽, 이중 창호 | WECPNL 기준 |
| 공사장 소음 | 임시 방음 시설 | 65dB 이하 (주간) |

#### 1-4. 음향 시뮬레이션 계획
- **전산 음향 해석**: ODEON, CATT-Acoustic, Ease 프로그램 활용
- **3D 음향 모델** 구축 → 재료 흡음 특성 입력 → RT60, SPL 분포 검토
- **오로라 플러그인**: Impulse Response 분석
- **1/10 축소 모형 실험**: 대형 공연장 계획 시 물리 모형 검증

### 2. 스마트 빌딩 시스템 (Smart Building System)

#### 2-1. 스마트 빌딩 개념 및 목표
스마트 빌딩 3대 목표

쾌적성 (Comfort) 효율성 (Efficiency) 안전성 (Safety)
├── 실내 환경 최적화 ├── 에너지 절감 ├── 화재·재난 대응
├── 개인 맞춤 환경 제어 ├── 설비 최적 운전 ├── 보안·출입 통제
└── 공간 활용 최적화 └── 유지관리 비용 절감 └── 비상 상황 대응


#### 2-2. 스마트 빌딩 핵심 시스템 구성

**IBMS (Intelligent Building Management System)**

| 서브시스템 | 주요 기능 | 연동 설비 |
|----------|----------|----------|
| BAS (빌딩자동화) | 공조·냉난방·조명 통합 제어 | AHU, FCU, 조명 |
| EMS (에너지관리) | 전력·열·가스 사용량 모니터링 | 전력량계, 열량계 |
| FAS (화재경보) | 화재 감지·경보·제어 | 감지기, 스프링클러 |
| CCTV·보안 | 영상 감시·출입 통제 | 카메라, ACS |
| 주차관제 | 차량 입출차·빈자리 안내 | 번호판 인식기 |
| 방송·안내 | 비상방송·일반방송 | PA 시스템 |

**IoT 센서 네트워크 계획**
센서 종류 및 측정 항목
├── 온·습도 센서: 실내 열환경 모니터링
├── CO₂ 센서: 공기질 기반 환기량 제어
├── 미세먼지(PM2.5) 센서: 외기 도입 제어
├── 재실 감지 센서: 공조·조명 자동 제어
├── 조도 센서: 주광 연동 조명 디밍 제어
├── 전력량계: 회로별 전력 사용량 측정
└── 누수 감지 센서: 기계실·지하층 배치

네트워크 구성
├── 유선: Ethernet (BACnet/IP)
├── 무선: Zigbee, Z-Wave, LoRa, Wi-Fi
└── 게이트웨이: 프로토콜 변환 및 데이터 집계


#### 2-3. 스마트 빌딩 제어 시나리오

| 시나리오 | 트리거 | 동작 |
|---------|--------|------|
| 출근 모드 | 시간 스케줄 (08:00) | 공조 ON, 조명 점등, 엘리베이터 상향 집중 |
| 퇴근 모드 | 시간 스케줄 (19:00) | 공조 OFF, 조명 소등, 보안 ON |

| 화재 모드 | FAS 연동 | 제연 ON, 엘리베이터 귀환, 비상방송 |
| 절전 모드 | 재실 없음 감지 | 조명·공조 절전 운전 |
| 쾌적 모드 | CO₂ ≥ 1,000ppm | 외기 도입량 자동 증가 |

### 3. 디지털 엔지니어링 & BIM

#### 3-1. BIM 수행 계획 (BIM Execution Plan)

**BIM 적용 목표 및 범위**
기본설계 단계 BIM 목표
├── LOD 300 수준 모델 구축
├── 다분야 통합 모델 클래시(Clash) 검토
├── 물량 산출 기반 공사비 개략 검증
└── 시각화·프레젠테이션 활용

LOD (Level of Development) 기준
├── LOD 100: 개념 매스 모델 (계획설계)
├── LOD 200: 개략 형태·치수 (계획설계 완료)
├── LOD 300: 정확한 형태·위치·치수 (기본설계)
├── LOD 350: 접합부·연결 상세 (실시설계)
└── LOD 400: 제작·시공 상세 (시공 단계)

**본 제안서는 계획설계단계로 **LOD 200**으로 진행한다. 

#### 3-2. BIM 소프트웨어 체계

| 분야 | 소프트웨어 | 용도 |
|------|-----------|------|
| 건축 모델링 | Revit Architecture | 건축 BIM 모델 |
| 구조 모델링 | Revit Structure / Tekla | 구조 BIM 모델 |
| MEP 모델링 | Revit MEP | 기계·전기 BIM 모델 |
| 클래시 검토 | Navisworks | 다분야 통합 검토 |
| 시각화 | Enscape / Lumion | 렌더링·VR |
| 협업 플랫폼 | BIM 360 / ACC | 클라우드 협업 |
| GIS 연동 | ArcGIS / Civil 3D | 대지·토목 연계 |
| 구조해석 연동 | ETABS / MIDAS 연동 | 해석 모델 연계 |

#### 3-3. 다분야 통합 클래시(Clash) 검토

**클래시 유형 및 대응**

| 클래시 유형 | 정의 | 우선순위 |
|-----------|------|---------|
| Hard Clash | 부재 간 물리적 충돌 | 최우선 해결 |
| Soft Clash | 유지관리 공간 부족 | 우선 해결 |
| Workflow Clash | 시공 순서 충돌 | 시공 단계 검토 |

**클래시 검토 프로세스**
분야별 BIM 모델 구축 (건축·구조·기계·전기)

통합 모델 취합 (Navisworks)
│
▼
클래시 검출 실행
├── 구조 vs 기계 (덕트·배관 vs 보·슬래브)
├── 구조 vs 전기 (트레이·전선관 vs 구조체)
├── 기계 vs 전기 (덕트 vs 케이블 트레이)
└── 건축 vs MEP (마감·천장 vs 설비)
│
▼
클래시 목록 작성 및 분야별 배포
│
▼
협의 및 설계 수정
│
▼
재검토 및 클래시 Zero 확인

#### 3-4. 디지털 트윈 (Digital Twin) 계획
디지털 트윈 구축 단계

기본설계 단계 (현재)

#### 3-5. 파라메트릭 설계 (Parametric Design)

- **Grasshopper (Rhino 연동)**: 외피·구조 형태 최적화
- **Dynamo (Revit 연동)**: 반복 모델링 자동화, 데이터 연동
- **활용 예시**
  - 외피 패널 배열 최적화 (일사·조망 동시 고려)
  - 구조 그리드 변수 조정에 따른 자동 모델 업데이트
  - 실별 면적 자동 집계 및 프로그램 검증

#### 3-6. 성능 기반 설계 (Performance-Based Design)

**시뮬레이션 종류 및 도구**

| 시뮬레이션 | 도구 | 검토 항목 |
|----------|------|----------|
| 일조·채광 분석 | Ladybug / Radiance | 일조 시간, 조도 분포 |
| 자연환기 분석 | CFD (Autodesk CFD) | 기류 속도·방향 |

| 화재·피난 시뮬레이션 | PyroSim / Pathfinder | 피난 시간, 연기 확산 |
| 음향 시뮬레이션 | ODEON / EASE | RT60, SPL 분포 |

#### 3-7. BIM 데이터 관리 계획

속성 정보 (BIM 파라미터) 관리

└── 유지관리 정보 (제조사, 보증 기간)

## 🔄 Implementation Workflow
STEP 1. 특수 엔지니어링 요구사항 분석
├── 발주처 요구 스마트 기능 목록 수렴
├── 음향 요구 공간 목록 파악
└── BIM 납품 기준 확인 (발주처 BIM 가이드라인)
│
  ▼
STEP 2. BIM 수행 계획서 (BEP) 작성
├── BIM 목표·범위·LOD 기준 확정
├── 소프트웨어·협업 플랫폼 선정
├── 분야별 BIM 담당자 지정
└── 클래시 검토 일정 계획
│
  ▼

├── 건축·구조·기계·전기 모델 개별 구축
├── LOD 300 수준 달성
└── 공통 좌표계·기준층 통일
│
  ▼
STEP 4. 음향 계획 수립
├── 음향 대상 공간 확정

├── 흡음·반사·확산 계획 수립
├── 소음·진동 차단 계획 수립
└── 음향 시뮬레이션 수행
│
  ▼
STEP 5. 스마트 빌딩 시스템 계획 수립
├── IBMS 구성 범위 확정
├── IoT 센서 종류·수량·위치 계획
├── 제어 시나리오 작성
└── 스마트 빌딩 인증 목표 확정

## 8. UI 구현 및 프론트엔드 작업 프로세스 (Implementation Workflow)

**본 특수 엔지니어링 지식을 `SpecialEngineeringPanel.tsx` UI로 구현할 때 참조해야 할 가이드라인입니다. (김해제2특수학교 메타데이터 반영)**

### 8.1. 레이아웃 구조 (Grid Layout - Col 12)
이 화면은 `App.tsx`의 "특수 엔지니어링 검토" 탭 선택 시 노출됩니다. 다른 엔지니어링 패널과 동일한 UI 프레임을 유지합니다.

1. **Header 영역:** `특수 엔지니어링: 음향·스마트빌딩·BIM` 타이틀 및 요약. 아이콘은 `Lightbulb` 또는 `Cpu` 활용.
2. **Section 1: 실내 음향 및 차음 계획 (Col 1-12)**
    *   다목적 체육관, 음악치료실 등 특수 활동 공간에 대한 층간 소음/차음(STC 50 이상) 및 최적 잔향시간(RT60) 지표 등 공간별 음향 목표 시각화.
3. **Section 2: IBMS 및 스마트 빌딩 시나리오 (Col 1-6)**
    *   호흡기/면역 민감 대상을 위한 CO2 및 미세먼지(PM2.5) 센서 연동 실내 공기질 스마트 제어 시나리오 명시.
4. **Section 3: 디지털 엔지니어링 & BIM (Col 7-12)**
    *   BIM LOD 수준 목표 및 "휠체어 전용 램프 vs 설비 기계 덕트 간의 간섭(Clash)" 3D 사전 검출 절차 명기.
5. **Section 4: 리스크 및 이슈 관리 (Risk Management) (Col 1-12)**
    *   화면 최하단 테이블. "음악치료실/수중운동실 소음 및 진동 제어", "스마트 센서 노후화 관리", "BIM 협업 프로세스 충돌" 등 리스크와 완화 조치 표기.
