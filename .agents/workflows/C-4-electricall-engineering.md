# 건축 전기 설비 엔지니어링
### MEP - Electrical | 기본설계 단계

---

## 📌 Description

기본설계 단계의 전기 설비 엔지니어링은 건축물의 안정적인 전력 공급과
효율적인 전기 에너지 운용을 위한 수변전, 간선, 동력, 조명, 약전·통신
시스템을 체계적으로 계획하는 분야입니다.

건물 용도·규모·운영 특성에 맞는 전기 시스템을 선정하고,
안전성·경제성·유지관리성을 종합적으로 고려한 최적의
전기 설비 설계 방향을 제시합니다.

---

## 📋 Contents

### 1. 수변전 설비 계획

#### 1-1. 수전 방식 선정

| 수전 방식 | 수전 전압 | 적용 규모 | 특징 |
|----------|----------|----------|------|
| 저압 수전 | 220/380V | 소규모 (계약전력 75kW 미만) | 변압기 불필요, 단순 |
| 고압 수전 | 22.9kV | 중규모 (75kW~10,000kW) | 수변전실 필요, 일반적 |
| 특고압 수전 | 154kV | 대규모 (10,000kW 초과) | 별도 변전소 수준 설비 |

#### 1-2. 수전 방식 신뢰도 구성
단일 회선 수전 (Single Feed)
└── 적용: 일반 건물 / 정전 허용 가능한 경우

2회선 수전 (Dual Feed)
├── 상시 2회선 동시 운전 방식
└── 적용: 병원·데이터센터·방송국 등 무정전 필수 시설

루프(Loop) 수전
└── 적용: 대규모 단지, 캠퍼스형 시설

#### 1-3. 변압기 용량 산정
변압기 용량 산정 절차

STEP 1. 부하설비 용량 집계
├── 동력 부하 (공조기, 펌프, 엘리베이터 등)
├── 전등·콘센트 부하
└── 특수 부하 (서버, 의료기기 등)

STEP 2. 수요율 적용
변압기 용량(kVA) = Σ(설비용량 × 수요율) / 역률

수요율 기준 (일반)
├── 전등·콘센트: 0.60.8
├── 동력 설비: 0.50.7
└── 특수 설비: 0.8~1.0

STEP 3. 여유율 적용
최종 용량 = 산정 용량 × 1.2 (20% 여유)


#### 1-4. 변압기 종류 선정

| 종류 | 특징 | 장점 | 단점 | 적용 |
|------|------|------|------|------|
| 유입 변압기 | 절연유 냉각 | 경제적, 효율 우수 | 화재 위험, 실내 설치 제한 | 옥외 변전소 |
| 몰드 변압기 | 에폭시 수지 절연 | 난연성, 유지관리 용이 | 고비용 | 실내 수변전실 |
| 아몰퍼스 변압기 | 아몰퍼스 철심 | 무부하 손실 75% 저감 | 고비용 | 에너지 절감 목적 |

#### 1-5. 수변전실 계획

- **위치 선정 기준**
  - 부하 중심부 배치 → 간선 손실 최소화
  - 외부 인입 케이블 경로 확보 용이한 위치
  - 변압기·큐비클 반입 경로 확보 (반입구 폭 1.5m 이상)
  - 침수 위험 지역 배제 (지하 최저층 지양)

- **수변전실 면적 기준 (개략)**

| 계약 전력 | 개략 면적 |
|----------|----------|
| 500kW 이하 | 30~50 ㎡ |
| 500~2,000kW | 50~150 ㎡ |
| 2,000~5,000kW | 150~300 ㎡ |
| 5,000kW 초과 | 300 ㎡ 이상 |

### 2. 비상 전원 설비 계획

#### 2-1. 비상발전기 계획
비상발전기 용량 산정
├── 소방 부하 (스프링클러펌프, 제연팬, 비상조명 등)
├── 비상 동력 부하 (비상용 엘리베이터, 급수펌프 등)
└── 보안·통신 부하 (서버, 방송, CCTV 등)

운전 방식
├── 자동 기동: 정전 후 40초 이내 전력 공급 (소방법 기준)
└── 수동 기동: 비소방 비상 부하

연료 방식
├── 경유 (디젤): 일반적 적용, 72시간 이상 연료 저장
└── 가스 (LNG): 연료 저장 불필요, 공급 안정성 검토 필요

발전기실 계획
├── 방음·방진 처리 (소음 기준: 부지 경계 65dB 이하)
├── 배기 덕트 외부 방출 경로 확보
├── 연료 탱크 위치 (내화 구조 격리 보관)
└── 냉각 방식: 라디에이터 냉각 (공냉식) 일반 적용


#### 2-2. UPS(무정전 전원장치) 계획

| 적용 대상 | 용량 | 백업 시간 |
|----------|------|----------|
| 전산·서버실 | 부하의 100~120% | 10~30분 |
| 방재센터·방송실 | 부하의 100% | 30분 이상 |
| 의료 생명유지장치 | 부하의 100% | 발전기 기동까지 |
| 보안·출입통제 | 소용량 | 2~4시간 |

### 3. 간선 설비 계획

#### 3-1. 간선 경로 계획
간선 계통 구성
수변전실
│
▼
주배전반 (MDB: Main Distribution Board)
│
├── 층별 분전반 (DB: Distribution Board)
│ └── 전등·콘센트 회로
│
├── 동력 제어반 (MCC: Motor Control Center)
│ └── 공조기, 펌프, 팬 등
│
└── 특수 부하 전용 회로
└── 서버, 의료기기, EV 충전기 등


#### 3-2. 전기 샤프트(EPS) 계획

- **EPS 위치**: 부하 중심부, 각 층 동일 위치 수직 관통
- **EPS 면적 기준**

| 연면적 | EPS 개략 면적 |
|--------|-------------|
| 3,000㎡ 이하 | 1~2 ㎡ |
| 3,000~10,000㎡ | 2~4 ㎡ |
| 10,000㎡ 초과 | 4~8 ㎡ (분할 또는 확대) |

- **케이블 포설 방식**
  - 케이블 트레이(Tray): 대용량 간선, 유지보수 용이
  - 금속 덕트: 다수 케이블 집중 포설 구간
  - 전선관(Conduit): 분기 회로, 매입 배선

#### 3-3. 케이블 선정 기준

| 구분 | 케이블 종류 | 적용 |
|------|-----------|------|
| 일반 간선 | TR-CV, TR-CNCV | 수변전실~분전반 |
| 내화 케이블 | FR-CV, HIV | 소방 전용 회로 |
| 저독성 케이블 | HFIX, HFCO | 피난 경로, 지하층 |
| 고압 케이블 | CV, CNCV-W | 22.9kV 인입 |

#### 3-4. 접지 설비 계획

| 접지 방식 | 특징 | 적용 |
|----------|------|------|
| 공통 접지 | 전체 설비 단일 접지 | 일반 건물 |
| 단독 접지 | 설비별 개별 접지 | 의료시설, 정밀기기 |
| 통합 접지 | 구조체 철근 활용 | 초고층, 대규모 |
| 피뢰 접지 | 피뢰침 전용 접지 | 피뢰 설비 연계 |

- 접지 저항 기준
  - 제1종: 10Ω 이하 (고압 이상 기기 외함)
  - 제2종: 150/Ig Ω 이하 (변압기 중성점)
  - 제3종: 100Ω 이하 (400V 미만 기기 외함)
  - 특별 제3종: 10Ω 이하 (400V 이상 기기 외함)

### 5. 조명 설비 계획

#### 5-1. 용도별 조도 기준 (KS A 3011)

| 공간 용도 | 권장 조도 | 비고 |
|----------|----------|------|
| 사무실 (일반) | 500 lx | 작업면 기준 |
| 회의실 | 500~750 lx | |
| 로비·홀 | 200~300 lx | |
| 복도·계단 | 100~150 lx | |
| 주차장 | 50~75 lx | |
| 화장실 | 200 lx | |
| 병원 병실 | 100~200 lx | |
| 판매장 | 750~1,000 lx | |
| 공장 (정밀작업) | 1,000~1,500 lx | |

#### 5-2. 조명 기구 선정

- **LED 조명** 전면 적용 (에너지소비효율 1등급 이상)
- **조명 밀도(LPD: Lighting Power Density)** 기준 준수
  - 사무실: 11W/㎡ 이하
  - 판매시설: 15W/㎡ 이하
  - 주거: 6W/㎡ 이하

#### 5-3. 조명 제어 시스템
조명 제어 방식
├── ON/OFF 스위치: 단순 공간
├── 디밍(Dimming) 제어: 조도 연속 조절
│ └── DALI(Digital Addressable Lighting Interface) 적용
├── 재실감지 센서: 사람 없을 때 자동 소등
│ └── PIR(열적외선) 또는 초음파 센서
├── 주광 연동 제어: 외부 밝기에 따라 자동 조절
│ └── 창측 조명 우선 조절
└── 중앙 집중 제어 (BEMS 연동)
└── 스케줄·시나리오 설정 가능


#### 5-4. 비상 조명 계획

- **비상조명등**: 정전 시 바닥면 조도 1lx 이상 (60분 이상 유지)
- **유도등**: 피난 방향 표시, 상시 점등 원칙
  - 대형 피난구 유도등: 피난구 상단 설치
  - 통로 유도등: 복도·계단 바닥 또는 벽면 1m 이하
- **비상 전원**: 축전지 내장형 또는 중앙 집중 방식

### 6. 약전·통신 설비 계획

#### 6-1. 정보통신 설비

| 설비 | 규격 | 비고 |
|------|------|------|
| 구내 통신망 (LAN) | UTP Cat.6A 이상 | 10Gbps 지원 |
| 광케이블 (백본) | Single Mode 광케이블 | MDF~IDF 구간 |
| 인터넷 인입 | 광케이블 인입 | 통신사 협의 |
| Wi-Fi AP | Wi-Fi 6(802.11ax) | 50~100㎡당 1개소 |
| MDF실 | 인입 케이블 집결 | 수변전실 인근 배치 |
| IDF실 | 층별 분배 | 각 층 EPS 인근 |

#### 6-2. 방송 설비
- **비상방송 겸용 PA 시스템** 구성 (소방법 기준 충족)
- 스피커 배치: 수평 거리 25m 이하, 음압 92dB 이상
- 방재센터 연동: 화재 시 자동 전환, 층별 선택 방송

#### 6-3. 보안·영상 설비

| 설비 | 사양 | 설치 기준 |
|------|------|----------|
| CCTV | IP 카메라, 2MP 이상 | 주출입구·주차장·엘리베이터 필수 |
| NVR | 저장장치 | 30일 이상 저장 |
| 출입통제 (ACS) | RFID·생체인식 | 주요 출입구·서버실 |
| 방문자 관리 | 무인 안내 시스템 | 로비 연계 |
| 주차관제 | 번호판 인식 | 지하주차장 출입구 |

#### 6-4. 빌딩 자동화 시스템 (BAS/BMS)
BAS 구성 체계
├── 중앙 감시반 (방재센터)
│ ├── 공조·냉난방 제어 모니터링
│ ├── 조명 제어 연동
│ ├── 전력 모니터링 (EMS)
│ └── 설비 고장 경보
│
├── DDC 컨트롤러 (현장 제어)
│ └── 각 설비 직접 제어
│
└── 네트워크 프로토콜
├── BACnet (국제 표준)
├── LonWorks
└── Modbus

### 7. 피뢰·전기안전 설비 계획

#### 7-1. 피뢰 설비 계획

- **피뢰 방식 선정**
  - 돌침(Franklin Rod) 방식: 일반 건물
  - 수평 도체(Mesh) 방식: 평지붕 건물
  - 능동형 피뢰침(ESE): 보호 반경 확대 필요 시

- **피뢰 보호 레벨 (KS C IEC 62305)**

| 보호 레벨 | 포획 효율 | 적용 |
|----------|----------|------|
| Level I | 99% | 폭발물 저장, 원자력 |
| Level II | 97% | 병원, 통신 시설 |
| Level III | 91% | 일반 주거·상업 |
| Level IV | 84% | 일반 구조물 |

#### 7-2. 서지보호장치 (SPD) 계획
- 수변전실 주배전반: Class I SPD 설치
- 층별 분전반: Class II SPD 설치
- 정밀기기 전용 회로: Class III SPD 설치

## 🔄 Implementation Workflow
STEP 1. 전기 부하 기초 조사
├── 건물 용도·규모·층수 파악
├── 주요 기계 설비 부하 목록 수령 (기계팀 협의)
└── 지역 전력 공급 조건 확인 (한전 협의)
 │
  ▼
STEP 2. 수변전 계획 수립
├── 부하 집계 및 변압기 용량 산정
├── 수전 방식 선정 (단일/2회선/루프)
├── 수변전실·발전기실 위치 및 면적 확정
└── 비상전원 (발전기·UPS) 용량 산정

 │
  ▼
STEP 3. 간선·동력 계획 수립
├── 간선 계통도 작성
├── EPS 위치 및 면적 확정 (건축팀 협의)
├── 케이블 트레이 경로 계획
└── 접지 방식 선정

 │
  ▼
STEP 4. 조명 계획 수립
├── 용도별 조도 기준 적용
├── 조명 기구 선정 (LED, LPD 기준)
├── 조명 제어 시스템 선정
└── 비상 조명·유도등 배치 계획

 │
  ▼
STEP 5. 약전·통신·보안 계획 수립
├── 정보통신 설비 구성 계획
├── 방송·보안·CCTV 계획
└── BAS/BMS 구성 계획

 │
  ▼

## 8. UI 구현 및 프론트엔드 작업 프로세스 (Implementation Workflow)

**본 전기 설비 엔지니어링 지식을 `ElectricalEngineeringPanel.tsx` UI로 구현할 때 참조해야 할 가이드라인입니다. (김해제2특수학교 메타데이터 반영)**

### 8.1. 레이아웃 구조 (Grid Layout - Col 12)
이 화면은 `App.tsx`의 "건축 전기 설비 엔지니어링" 탭 선택 시 노출됩니다. 다른 엔지니어링 패널과 동일한 UI 프레임을 유지합니다.

1. **Header 영역:** `건축 전기/통신 시스템 분석서` 타이틀과 분석 요약. 아이콘은 `Zap`(번개) 활용.
2. **Section 1: 수변전 및 비상전원 계획 (Col 1-12)**
    *   **(좌측단 7/12):** 적정 변압기 용량 산정 및 고압(22.9kV) 수전 개념 도입. 특수 설비 수요율 반영.
    *   **(우측단 5/12):** 무정전전원장치(UPS) 및 비상발전기(특수치료실 및 재난대피소 대응) 용량 백업 가동률 시각화.
3. **Section 2: 스마트 조명 및 시각 보호 제어 (Col 1-6)**
    *   특수학교 재학생(빛 민감성 학생)을 위한 Flicker-Free 조명 설계 및 DALI 기반 눈부심(Glare) 디밍 제어 시스템 표기.
4. **Section 3: 통합/통신 및 생활 안전 보안 (Col 7-12)**
    *   돌봄 교실 지능형 CCTV, 비상호출벨(휠체어 화장실 및 수중운동실) 연계 10Gbps 초고속 통신 제어 시스템 강조.
5. **Section 4: 리스크 및 이슈 관리 (Risk Management) (Col 1-12)**
    *   화면 최하단 테이블. "응급치료기기 전원 차단", "직사 광원 노출에 의한 심적 불안감", "EPS실 공간 부족" 항목 대응 방안 명기.
