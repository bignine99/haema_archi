# 과업지시서 분석 엔진
### Design Brief Intelligence | 기본설계 단계
#### PDF 파싱 · 규정 추출 · 기본설계 핵심요건 구조화 · 설계 반영 체크리스트

---

## 📌 Description

본 SKILL은 과업지시서(PDF, DOC, HWP 등)를 자동 분석하여
기본설계 단계에 반드시 반영해야 하는 발주 조건, 법규 조건,
공간 프로그램, 인증 요구사항, 공정·납품 요구사항을
누락 없이 구조화하는 **과업지시서 분석 엔진**의 작성 기준이다.

단순 요약이 아니라, 과업지시서 내용을 다음 5개 층위로 재구성해야 한다.

1. **사업 기본조건**
2. **설계 의무사항 및 제한조건**
3. **분야별 기본설계 반영사항**
4. **일정·협의·인허가·성과품 요구사항**
5. **설계 리스크 및 우선 검토사항**

즉, “읽은 내용”이 아니라  
**기본설계에 즉시 적용 가능한 설계 입력값(Design Input)** 으로 변환하는 것이 목적이다.

### 3. 기본설계용 “설계 입력값”으로 재구성

#### 3-1. 법적·계획적 제한조건
| 구분 | 설계 입력값 |
|---|---|
| 층수 | 5층 이하 |
| 용적률 | 180% 이하 |
| 건폐율 | 60% 이하 |
| 연면적 | 14,157㎡ ±5% |
| 교실 기준 | 일반교실 63㎡ 이상 |
| 복도폭 | 법적 2.4m 이상 + 장애학생 교행폭 고려 |
| 주차 | 법정대수 이상, 실제 수요 고려 확대 |
| 지하층 | 최소화 권장 |
| 증축 대응 | 구조 및 열원설비 확장성 확보 |

#### 3-2. 배치 및 동선 핵심조건
배치 필수 반영사항
├── 보행자 / 차량 동선 명확 분리
├── 학생 등하교 동선과 교직원 차량동선 분리
├── 급식차량 동선과 보행자 출입동선 분리
├── 북서측 횡단보도에서 차량출입 최대한 이격
├── 주차장은 입구 쪽 배치 권장
├── 일반교실은 채광·환기 유리한 위치
├── 소음 영향 적은 곳에 일반교실 우선 배치
└── 시청각실·급식실은 우천 시 실내연결동선 확보

#### 3-3. 특수학교 특화 설계조건
| 항목 | 설계 입력값 |
|---|---|

| 교육과정 | 고등부/전공과 조닝 구분 |

### 4. 분야별 기본설계 반영 체크 항목

### 4-1. 건축
- 5층 이하 매스 계획
- 일반교실 남향/남동향 우선 배치
- 공용공간의 단순 통로화 지양
- 강당·식당·도서관의 복합화 및 지역개방성 검토
- 곡면 과다 사용 지양
- 색채계획 3안 이상 작성 고려
- 일조 민원 최소화 배치 검토
- 옥상은 태양광 설치와 병행 가능한 계획 우선

### 4-2. 구조
- 내진설계 필수
- 비구조요소 내진 포함
- 지질조사 5공 결과 반영
- 향후 증축 대응 구조 계획
- 옥상 구조물, 외부 구조물, 커튼월 구조검토
- 파일/매트 등 기초형식은 조사 후 확정
- 하중조합에 의한 구조 검토
- 주차장 및 외장재 하중 검토

### 4-3. 토목
- 현황측량 및 경계측량 필수
- 절·성토 균형 계획
- 흙막이 가시설 및 계측 포함
- 오·우수 분리
- 우수 유입이 교사동으로 흐르지 않도록 계획
- 하수도 접속, 인근 관망도 및 수리계산 검토
- 하천 인접부지 공사 중 환경·안전 대책 고려
- 운동장은 마사토 계획 원칙

### 4-4. 기계설비
- 학교 실별 특성에 맞는 공조 조닝
- 폐열회수형 환기장치 적용 대상 반영
- 고효율·친환경 설비 우선
- BEMS 예비인증 대응
- 열원 LCC 검토
- 증축 대비 열원 및 장비스페이스 고려
- 급식실 환기·위생 동선 고려
- 기계실 지상 설치 우선, 지하 시 침수대책 필수

### 7. AI가 반드시 수행해야 하는 “개선 기능”

#### 7-1. 충돌 검출
자동 충돌 검출 항목
├── 사용자 입력 조건 vs 과업지시서 원문
├── 요약값 vs 원문 수치
├── 층수/용적률/면적 상충
├── 법정 기준 vs 발주청 강화 기준
└── 프로그램 면적합 vs 총연면적

#### 7-2. 중요도 태깅
| 태그 | 의미 |
|---|---|
| 필수 | 미반영 시 과업 위반 |
| 핵심 | 기본설계 초기 의사결정 필수 |
| 중요 | 조기 검토 필요 |
| 협의 | 발주청 협의 후 확정 |
| 주의 | 민원/하자/비용 리스크 항목 |

#### 7-3. 설계 반영 문장 자동 생성
예시:
- “본 사업은 학교용지로서 5층 이하 계획이 필수이며, 초기 매스 스터디 단계에서 해당 조건을 최우선 반영하여야 함.”
- “일반교실은 채광·환기·정온환경을 고려하여 남향 또는 남동향 우선 배치를 검토함.”
- “학생 안전 확보를 위해 보행동선과 차량동선은 물리적으로 분리하고, 급식차량 동선과 주출입 동선의 중첩을 방지함.”

## 🔄 Implementation Workflow
STEP 1. 문서 파싱
├── PDF 텍스트 추출
├── 표/서식/별첨 분리
└── 문단 번호 체계 인식
  │
  ▼
STEP 2. 핵심 조건 추출
├── 사업 기본정보 추출
├── 법적 제한값 추출
├── 인증 요구 추출
├── 공간 프로그램 추출
└── 일정·납품 요구 추출
  │
  ▼
STEP 3. 설계 입력값 변환
├── 기본설계용 수치값 정리
├── 분야별 체크리스트 생성
├── 충돌 항목 탐지
└── 발주청 강화 기준 별도 표기
  │
  ▼
STEP 4. 우선순위 재구성
├── 필수 / 핵심 / 중요 / 협의 / 주의 분류
├── 기본설계 즉시 반영 항목 도출
└── 실시설계 이월 항목 분리
  │
  ▼
STEP 5. 결과물 생성
├── 과업지시서 요약 카드
├── 기본설계 체크리스트
├── 분야별 설계 반영표
├── 일정 및 협의표
└── 리스크 및 누락 주의사항

## 🎨 UI 구현 및 프론트엔드 작업 프로세스 (High-Fidelity)

고품질의 전문가용 AI 과업지시서 분석 패널 구축을 위해, 이후 개발되는 모든 Phase C 형태의 패널과 동일한 수준의 시각적 완성도(High-Fidelity)를 적용합니다.

### 8-1. 12-Column Grid 레이아웃 적용
방대한 텍스트 위주의 과업지시서 분석 결과를 체계화하기 위해 12-Column CSS Grid를 도입합니다.
- **좌측/중앙 (col-span-8)**: 면적, 용도, 층수 등 기초 조건과 설계/일반 지침, 성과품 분류표 등 주요 텍스트 뭉치를 리스트(Bullet)나 표 형태로 가독성 있게 배치.
- **우측 (col-span-4)**: 분석 완료 품질 검증(Seal), 우선 점검 대상(Key Notes), 마이크로서비스 연동 상태(Status) 등을 세로 카드 뷰로 구성해 집중도를 높임.
- **하단 (col-span-12)**: 과업수행 시 발생할 수 있는 리스크(기간 타이트, 층수 고정 등)를 식별하고 해소 방안을 도출하는 100% 폭의 리스크 매트릭스(Risk Mitigation Table) 배치.

### 8-2. 데이터 표시 디자인 시스템
- **색상 팔레트**: 신뢰감을 주는 Indigo / Blue / Slate 계열을 스킴으로 적용하고, 과업지시서 파싱 로직 완료 시 시각적인 성취감을 주기 위해 그라데이션 강조 효과 추가.
- **엔지니어링 데이터 실(Seal)**: 우측 상단 영역에 고급스러운 방패/메달 메타포의 `RFP Analysis Complete` 뱃지를 배치하여 AI 문서 판독이 무결하게 끝났음을 증명.
- **문서 업로더 결합 (`DocumentUploader`)**: 헤더 혹은 패널 상단에 컴팩트하게 탑재하여 PDF 구문 분석(Parsing)과 결과물 출력이 One-Stop으로 이뤄지도록 구현.

### 8-3. 텍스트 파싱 데이터 최적화 (Clean Item)
- 법률 용어나 반복적 단어("하여야 한다", "제X조") 등의 Noise를 프론트엔드 단에서 마스킹(Clean Display Item)하여 분석 엔진의 결과물이 1줄짜리 명확한 '지시문'으로 요약되도록 구현.
