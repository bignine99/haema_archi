| 지표 | 수치 | 비고 |

### 사회적 타당성 요약

- 해당 권역 내 특수교육 수요 대상자는 연간 1,398명 수준으로 지속 증가 추세에 있음
- 지역사회 건립 동의율 98%는 특수학교에 대한 부정적 인식을 극복하고 지역 커뮤니티 거점으로서의 역할 전환이 이루어졌음을 의미함
- 단순 교육시설이 아닌 지역사회 통합형 공공시설로서의 포지셔닝이 설계 방향의 핵심 전제가 되어야 함

## 5. SKILL 체계 — 프로젝트 특성 분석 자동화

---

### SKILL A · DemandTrace — 수요 정량화 및 타당성 추적 엔진

**목적:** 특수학교 수요 데이터를 실시간으로 수집·분석하여 사업 타당성을 정량적으로 검증

**현재 문제:**
- 수요 대상자 수치(1,398명/년)의 출처 및 산정 기준 불명확
- 지역사회 동의율(98%)의 측정 방법 및 시점 미표시
- 수요 증가 예측의 근거 데이터 미연동

**구현 방향:**
[수요 타당성 자동 산정 모델]

입력값:

권역 내 특수교육 대상자 등록 현황 (교육부 공공데이터)
인근 특수학교 수용 인원 및 대기자 현황
인구 구조 변화 추이 (장래인구추계)
출력값:

연도별 수요 예측 곡선
현재 공급 대비 수요 갭 분석
사업 타당성 지수 (Demand Index)

**추가 출력물:**
- 수요 데이터 출처 자동 태깅 (공공데이터 API 연동)
- 수요 예측 신뢰구간 시각화 (5년/10년/20년)
- 지역사회 수용성 지수 산정 기준 명시

---

### SKILL B · SiteIQ — 대상지 광역 인프라 연계 분석 엔진

**목적:** 대상지 주변 인프라 현황을 자동 분석하여 입지 타당성 및 연계 설계 방향을 도출

**현재 문제:**
- 인프라 연계성이 정성적 설명에 그침
- 대중교통 접근성 및 보행 동선의 정량적 분석 미제공
- 주변 시설과의 공생 가능성 평가 기준 불명확

**구현 방향:**
[대상지 광역 분석 자동화 레이어]

경상남도 김해시 주촌면 농소리 631-2 기준

인프라 연계 항목:

대중교통 접근성: 버스 정류장 반경 및 노선 수
보행 접근성: 공공보행로 연결 현황 및 단차 구간 식별
주거 인프라: 반경 500m / 1km 내 공동주택 세대수
공공시설: 반경 1km 내 공공지원시설 현황
출력값:

인프라 연계성 점수 (100점 기준)
단차 및 물리적 장벽 위치 자동 표시
취약 동선 구간 우선 개선 권고

**추가 출력물:**
- GIS 기반 인프라 연계 지도 자동 생성
- 보행 취약 구간 단면도 자동 추출
- 유사 특수학교 입지 사례와 인프라 연계성 비교

---

### SKILL C · ZoneMatrix — 생애주기 기반 수직 조닝 최적화 엔진

**목적:** 사용자 특성 및 생애주기에 따른 기능별 수직 조닝을 자동으로 최적화하여 설계 근거를 제공

**현재 문제:**
- 층별 조닝이 정성적 판단에 의존
- 조닝 계획의 법규 적합성 자동 검토 미연동
- 사용자 동선 효율성 정량 평가 기준 없음

**구현 방향:**
[수직 조닝 최적화 알고리즘]

입력값:

사용자 그룹: 유치부 / 초등부 / 중등부 / 고등부 / 전공과
각 그룹별 이동 특성 (휠체어 의존도, 보행 자립도 등)
각 기능실별 면적 요구량 및 층별 배치 제약
조닝 최적화 기준:

이동 취약 그룹 최저층 배치 (접근 최단거리)
소음 발생 공간의 수직 분리 (체육 활동 공간 등)
관리 통제 거점과 각 학부 간 동선 거리 균등화
BF 인증 기준 충족을 위한 수직 동선 코어 위치 최적화
출력값:

층별 기능 배치 최적안 (1순위 / 2순위 / 3순위)
조닝 안별 BF 인증 기준 충족도 점수
조닝 안별 관리 효율성 지수

**추가 출력물:**
- 수직 조닝 다이어그램 자동 생성
- 층별 면적 배분 검토표 (법정 기준 대비)
- 유사 특수학교 조닝 사례 비교



### SKILL E · CommunityLink — 지역사회 통합 설계 지수 산정 엔진

**목적:** 특수학교가 지역사회와 물리적/시각적으로 공생할 수 있는 설계 요소를 정량화하여 평가

**현재 문제:**
- "열린 외부공간 연계"라는 설계 원칙이 정성적 선언에 그침
- 지역사회 통합 설계 요소의 정량적 평가 기준 없음
- 주민 수용성과 설계 방향의 연계 근거 미제공

**구현 방향:**
[지역사회 통합 설계 지수 (Community Integration Index)]

평가 항목 및 배점:

외부공간 개방성 (공개공지 비율, 경계부 투명성): 25점
지역 보행 동선 연계 (공공보행로 연결 수, 출입구 위치): 25점
공용 프로그램 계획 (지역 주민 개방 공간 면적 비율): 25점
시각적 공생성 (1층 전면부 투명도, 녹지 연속성): 25점
총점 기준:

90점 이상: 지역사회 통합 우수
75~89점: 지역사회 통합 양호
60~74점: 지역사회 통합 보통 (개선 권고)
60점 미만: 지역사회 통합 미흡 (재검토 필요)

**추가 출력물:**
- 지역사회 통합 설계 지수 레이더 차트
- 항목별 개선 권고 사항 자동 생성
- 유사 특수학교 지역사회 통합 사례 비교

## 🎨 UI 구현 및 프론트엔드 작업 프로세스 (High-Fidelity)

고품질의 전문가용 AI 과업지시서 분석 패널 구축을 위해, 이후 개발되는 모든 Phase A 형태의 패널과 동일한 수준의 시각적 완성도(High-Fidelity)를 적용합니다.

### 8-1. 12-Column Grid 레이아웃 적용
방대한 텍스트 위주의 과업지시서 분석 결과를 체계화하기 위해 12-Column CSS Grid를 도입합니다.
- **좌측/중앙 (col-span-8)**: 프로젝트 주요 타당성 지표, 입지 분석, 조닝 특성 등 핵심 데이터를 다이어그램과 표, 요약 형태로 가독성 있게 배치.
- **우측 (col-span-4)**: 분석 완료 품질 검증(Seal), 우선 점검 대상(Key Notes), SKILL 엔진 연동 상태(Status) 등을 세로 대시보드 뷰로 구성해 집중도를 높임.
- **하단 (col-span-12)**: 과업수행 시 발생할 수 있는 리스크를 식별하고 해소 방안을 도출하는 100% 폭의 리스크 매트릭스(Risk Mitigation Table) 배치 (필요시).

### 8-2. 데이터 표시 디자인 시스템
- **색상 팔레트**: 신뢰감을 주는 Indigo / Blue / Emerald 계열을 결합하여, 각 카테고리별(수요, 맵, 조닝)로 구별된 컬러 스킴 적용.
- **엔지니어링 데이터 실(Seal)**: 우측 상단 영역에 고급스러운 뱃지의 `PROJECT SKILL ENGINE` 뱃지를 배치하여 AI 분석 데이터가 무결하게 추론되었음을 인증.

### 8-3. 텍스트 파싱 데이터 최적화 (Clean Item)
- 반복되는 용어나 복잡한 서술형 텍스트를 카드형 UI로 재구성하고 핵심 키워드 중심의 `Clean Display Item`으로 요약하여 시인성을 극대화합니다.
