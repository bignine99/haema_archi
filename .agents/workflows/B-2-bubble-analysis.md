## 시스템 개요

| 항목 | 내용 |
|------|------|
| 모듈명 | 버블 다이어그램 모듈 (Spatial Adjacency Bubble Diagram) |
| 소속 Phase | Phase B. 공간 프로그래밍 |

## 1. 현행 시스템 구성 분석

### 1-1. Space Zoning 컬러 코딩 체계

| 컬러 | 존 구분 | 해당 공간 예시 |
|------|--------|--------------|
| Teal (청록) | 학습/업무 | 강당, 체육관, 교실, 컴퓨터실, 미디어 제작실 |
| Sage Green (세이지 그린) | 지원/공용 | 대강의실, 소강의실, 교수학습지원센터, 기계실 |
| Beige (베이지) | 특화/서비스 | 조리 실습실, 음악실, 물탱크실, 준비실 |
| Navy (네이비) | 기타/설비 | 행정실, 교장실, 냉각탑, 발전기실, 주차 관제실 |

### 1-2. Link Types 정의

| 링크 유형 | 표시 방식 | 의미 |
|----------|---------|------|
| Mandatory Adjacency | 실선 | 반드시 인접 배치 필요 (법정 또는 기능 필수) |
| Desired Adjacency | 점선 | 인접 배치 권장 (효율성 및 사용성 향상) |

### 1-3. Physics Engine 작동 원칙
각 노드(실)는 면적(Area)에 비례한 반지름을 가지며
조닝 그룹(Zoning Clusters) 및 무장애 동선(BF)을 위한
1.4m 휠체어 회전반경 버퍼(Buffer) 물리력이 엄격하게 적용됨

## 2. 현행 시스템 문제점 분석

### 2-1. 분석 및 해석 기능 부재 (핵심 문제)

| 문제 항목 | 현황 | 영향 |
|----------|------|------|
| 인접성 충족률 분석 없음 | 다이어그램 시각화만 제공 | Mandatory Adjacency 중 실제 충족된 비율 파악 불가 |
| 클러스터 응집도 분석 없음 | 존별 색상 구분만 제공 | 동일 존 내 실들의 물리적 분산 정도 파악 불가 |
| 문제 링크 자동 감지 없음 | 모든 링크 동일하게 표시 | 장거리 Mandatory Adjacency 위반 구간 식별 불가 |
| BF 버퍼 충족 여부 해석 없음 | 물리력 적용 후 결과만 표시 | 실제 1.4m 휠체어 회전반경 확보 여부 수치 미제공 |
| 층별 인접성 맥락 해석 없음 | 전체 층 혼합 표시 | 수직 인접성(층 간 관계) 분석 불가 |

### 2-2. 시각화 품질 문제

| 문제 항목 | 현황 | 영향 |
|----------|------|------|
| 노드 겹침 발생 | 일부 소규모 실 버블 겹침 확인 | 인접 관계 링크 가독성 저하 |
| 링크 과밀 구간 | 중앙부 링크 집중으로 판독 어려움 | 핵심 인접 관계 파악 어려움 |
| 실명 텍스트 잘림 | 소규모 버블에서 실명 생략 표시 | 공간 식별 불가 |
| 존 경계 불명확 | 컬러만으로 존 구분 | 존 클러스터 영역 시각적 구분 부족 |
| 면적 수치 미표시 | 일부 대형 실만 면적 표시 | 규모 비교 어려움 |

### 2-3. 기능 연동 문제

| 문제 항목 | 현황 | 영향 |
|----------|------|------|
| 층별 조닝 변경 미자동 연동 | 조닝 수정 후 수동 재배치 필요 | 설계 변경 시 다이어그램 갱신 지연 |
| 인접성 규칙 편집 불가 | 사전 설정된 인접성 규칙만 적용 | 프로젝트 특성 반영 커스터마이징 불가 |
| 결과 해석 텍스트 자동 생성 없음 | 다이어그램만 출력 | 발주처 보고 및 설계 근거 자료로 활용 불가 |

### SKILL B1 · AdjacencyRead — 인접성 충족률 자동 분석 엔진

**목적:** Mandatory 및 Desired Adjacency 규칙 대비 현행 다이어그램의 충족 현황을 정량적으로 분석

**현재 문제:**
- Mandatory Adjacency 링크가 시각적으로만 표시되고 실제 충족 여부 판단 기준 없음
- 물리 엔진 배치 결과가 인접성 목표를 얼마나 달성했는지 수치화 없음
- 위반 링크(장거리 연결)와 정상 링크의 구분 자동 감지 없음

**구현 방향:**
[인접성 충족률 자동 분석 모델]

분석 기준 정의:

Mandatory Adjacency 충족: 두 노드 중심 간 거리 ≤ (반지름 A + 반지름 B + 1.4m 버퍼)
Desired Adjacency 충족: 두 노드 중심 간 거리 ≤ (반지름 A + 반지름 B + 3.0m 버퍼)
위반: 위 기준 초과 시 자동 감지
자동 산출 지표:

Mandatory Adjacency 총 규칙 수: N개
충족 수: M개 (충족률: M/N × 100%)
위반 수: (N-M)개
위반 링크 목록 자동 추출 및 강조 표시
Desired Adjacency 달성률:

총 규칙 수 대비 달성 비율 별도 산출
특수학교 특화 분석:

치료실 ↔ 주 활동 교실 Mandatory 충족 여부 우선 검토
특수 화장실 ↔ 주 활동 교실 Mandatory 충족 여부 우선 검토
관리 거점 ↔ 각 학부 교실 Desired 충족 여부 검토

**자동 생성 해석 텍스트 예시:**
[인접성 충족률 분석 결과]

Mandatory Adjacency 충족률: 82% (18개 중 15개 충족)
미충족 3개 규칙:

치료실 ↔ 유치부 교실: 현재 이격거리 12.3m (기준: 5.2m 이하)
개선 제안: 치료실을 1F 유치부 교실 인접 배치 필요
보건실 ↔ 교장실: 현재 이격거리 8.7m (기준: 4.1m 이하)
개선 제안: 1F 행정 존 내 보건실 재배치 권고
소방 설비실 ↔ 비상 계단실: 현재 이격거리 9.1m
개선 제안: B1F 설비 존 내 인접 배치 필요
Desired Adjacency 달성률: 71% (24개 중 17개 달성)
종합 평가: 양호 (목표 기준: Mandatory 80% 이상, Desired 60% 이상)

**추가 출력물:**
- 인접성 충족률 요약 대시보드 (파이 차트 + 목록)
- 위반 링크 빨간색 강조 표시 (다이어그램 레이어 추가)
- 위반 심각도 3단계 (Critical / Warning / Minor) 자동 분류
- 개선 시 예상 충족률 변화 시뮬레이션

### SKILL B2 · ClusterScore — 존별 응집도 정량 분석 엔진

**목적:** 동일 존(Zone) 내 실들이 물리적으로 얼마나 응집되어 있는지를 정량화하여 조닝 계획의 완성도를 평가

**현재 문제:**
- 컬러 코딩으로 존 구분은 되나 실제 공간적 응집 여부 수치화 없음
- 다른 존의 버블이 특정 존 클러스터 내부에 침투하는 경우 자동 감지 없음
- 존별 중심점 및 분산 반경 정보 미제공

**구현 방향:**
[존별 응집도 지수 산출 모델]

응집도 지수 (Cluster Cohesion Index) 정의:

존 내 모든 실의 중심점 → 존 중심점까지 평균 거리 산출
값이 낮을수록 응집도 높음 (0에 가까울수록 이상적)
이질 침투 지수 (Cluster Purity Index) 정의:

존 경계 반경 내 타존 버블 수 / 전체 버블 수
값이 낮을수록 존 순수도 높음
존별 분석 결과 형식:
존 구분 | 실 수 | 응집도 지수 | 순수도 지수 | 평가
학습/업무 | 23개 | 2.8m | 91% | 우수
지원/공용 | 18개 | 3.5m | 84% | 양호
특화/서비스 | 12개 | 4.1m | 78% | 검토
기타/설비 | 15개 | 5.2m | 71% | 개선필요

특수학교 특화 클러스터 분석:

치료 지원 클러스터: 치료실 + 상담실 + 보건실 응집도 별도 산출
행정 관리 클러스터: 교장실 + 행정실 + 교무실 응집도 별도 산출
설비 클러스터: 기계실 + 전기실 + 발전기실 + 물탱크실 응집도 별도 산출

**자동 생성 해석 텍스트 예시:**
[존별 응집도 분석 결과]

기타/설비 존의 응집도 지수가 5.2m로 가장 낮습니다.
주요 원인: 발전기실이 체육관 인접부에 분산 배치되어
설비 클러스터 중심으로부터 이격 발생.
개선 제안: 발전기실을 B1F 기계실 인접부로 재배치하여
설비 존 응집도를 3.0m 이하로 개선 가능합니다.

특화/서비스 존 순수도 78%: 조리 실습실 인근에
학습/업무 존 버블 3개 침투 확인.
해당 구간 동선 분리 계획 검토 권고.

**추가 출력물:**
- 존별 응집도 레이더 차트
- 존 경계 반경 시각화 레이어 (다이어그램 오버레이)
- 이질 침투 버블 자동 표시 (테두리 경고 강조)
- 재배치 시 응집도 변화 예측 시뮬레이션

### SKILL B3 · BFVerify — 무장애 동선 버퍼 충족 검증 엔진

**목적:** 물리 엔진에 적용된 1.4m BF 버퍼가 실제로 충족되었는지 노드별로 검증하고 취약 구간을 자동 식별

**현재 문제:**
- "1.4m 휠체어 회전반경 버퍼 물리력이 엄격하게 적용됨"이라 표시되나 실제 충족 여부 수치 미제공
- 버블 겹침 발생 구간에서 BF 버퍼 위반 가능성 자동 감지 없음
- 특수학교 특성상 BF 기준 준수가 핵심임에도 검증 결과 미출력

**구현 방향:**
[BF 버퍼 충족 검증 모델]

검증 기준:

휠체어 회전반경: 1.4m (BF 인증 기준)
두 노드 간 최소 이격: 두 노드 각각의 BF 버퍼 합산
위반: 두 노드 중심 간 거리 < (반지름 A + 반지름 B + 2.8m)
검증 항목:

전체 노드 쌍 간 BF 버퍼 충족 여부 자동 계산
위반 쌍 자동 추출 및 이격 부족 거리 수치 표시
위반 심각도: Critical (0.5m 이상 부족) / Warning (0.5m 미만 부족)
동선 폭 연계 검증:

Mandatory Adjacency 링크 경로상 BF 동선 폭 확보 여부
목표: 주요 동선 유효폭 1.8m 이상 (광폭 램프 기준)
최소: 1.2m 이상 (장애인등편의법 기준)
특수학교 특화 BF 검증:

유치부/치료실 접근 동선 전 구간 1.8m 이상 확보 여부
휠체어 전용 코어(엘리베이터 홀) 인접 공간 회전 반경 확보 여부
특수 화장실 접근 경로 BF 연속성 확보 여부

**자동 생성 해석 텍스트 예시:**
[BF 버퍼 충족 검증 결과]

전체 노드 쌍 분석: 총 1,128쌍
BF 버퍼 충족: 1,089쌍 (96.5%)
BF 버퍼 위반: 39쌍 (3.5%)

Critical 위반 (0.5m 이상 부족): 8쌍

조리 실습실 ↔ 준비실: 이격 0.3m (필요: 2.8m, 부족: 2.5m)
냉각탑 ↔ 전기실: 이격 1.1m (필요: 2.8m, 부족: 1.7m)
→ 설비 공간 BF 기준 적용 필요성 재검토 권고
Warning 위반: 31쌍 (대부분 설비 존 내부)

BF 인증 사전 검토 평가: 주의 필요
학습/지원/특화 존 내 위반: 2쌍 → 즉시 개선 권고
설비 존 내 위반: 37쌍 → BF 적용 범위 기준 재확인 필요

**추가 출력물:**
- BF 위반 구간 다이어그램 오버레이 (빨간 테두리 + 이격 수치 표시)
- 위반 심각도별 목록 및 개선 방향 자동 제시
- BF 인증 사전 검토 점수 자동 산출
- 개선 배치 후 BF 충족률 재시뮬레이션

### SKILL B4 · VerticalAdjacency — 층간 수직 인접성 분석 엔진

**목적:** 현행 전체 층 혼합 표시 방식을 보완하여 층 간 수직 인접성 관계를 분석하고 설계 방향을 제시

**현재 문제:**
- 전체 층 혼합 표시로 층 간 수직 관계(예: 수직 동선 코어와 각 층 주요 실의 관계) 분석 불가
- 층별 필터 기능은 있으나 층 간 비교 분석 기능 없음
- 엘리베이터/계단 코어와 각 층 주요 실 간의 수직 인접성 검증 없음
