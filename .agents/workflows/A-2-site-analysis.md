# 대지현황 분석
### Site Analysis | 기본설계 단계
#### AI 기반 종합 대지분석 · 5대 영역 · SWOT · 디자인 전략

---

## 📌 Description

기본설계 단계의 대지현황 분석은 프로젝트의 설계 방향을 결정하는
가장 첫 번째 핵심 단계로, 대지의 물리적·환경적·사회적 특성을
종합적으로 분석하여 최적의 건축 계획 방향을 도출하는 분야입니다.

AI 기반 분석 엔진을 활용하여 5대 핵심 영역(물리적·미기후·인프라·
인문사회·종합전략)을 체계적으로 분석하고, SWOT 분석과 디자인 전략을
연계하여 설계팀과 발주처가 공유할 수 있는 종합 분석 콘텐츠를 제공합니다.

### 2. 5대 영역 상세 분석

#### 2-1. 영역 1: 물리적·기하학적 환경 분석

**핵심 산출 항목**
건축 가능 영역 산출
├── 최대 건축면적 = 대지면적 × 건폐율
├── 최대 연면적 = 대지면적 × 용적률
├── 유효 대지면적 = 대지면적 × 70~80%
│ (이격거리·조경·도로 제외)
└── 층별 평균 면적 = 연면적 / 계획 층수

이격거리 (Setback) 분석
├── 전면 이격: 도로 폭원 기준 (건축선 후퇴)
├── 측면 이격: 인접 대지 경계 기준
├── 후면 이격: 일조권 사선 제한
└── 실효 건축 가능 면적 산출


**추가 분석 항목 (기존 AI 결과 보완)**

| 분석 항목 | 내용 | 시각화 |
|----------|------|--------|
| 대지 형상 분석 | 장단변비, 방위각, 정형화 가능 범위 | 평면도 위 분석 레이어 |
| 법정 건축한계선 | 도로·경계선 이격 반영 | 색상 구분 영역도 |
| 고도제한 분석 | 사선제한·일조권·항공장애 통합 | 3D 볼륨 시각화 |
| 지형 단면 분석 | 절성토 예상 구간, 옹벽 필요 구간 | 단면 그래프 |
| 지하 매설물 | 상하수도·가스·통신 예상 위치 | 평면도 레이어 |
| 기초 형식 예측 | 지역 지반 DB 기반 예측 | 권장 공법 표 |

#### 2-2. 영역 2: 미기후 및 환경 성능 분석

**태양 궤적 분석 (신규 강화)**
절기별 태양 고도각 분석 (위도 기반 자동 산출)
├── 하지 (6/21): 최고 고도각 → 차양 계획 기준
├── 동지 (12/21): 최저 고도각 → 일조 확보 기준
├── 춘추분 (3/21, 9/21): 중간값 → 계절 전환 기준
└── 시간대별 일사 방향 분석 (오전/정오/오후)

방위별 일사 취득량 분석
├── 남향: 겨울 일사 취득 최대 → 주요 교실·거실 배치
├── 남동향: 오전 일사 취득 → 학습 공간 최적
├── 동향: 오전 일사, 오후 차단 → 침실·주거 적합
├── 서향: 오후 일사 과다 → 차양 계획 필수
└── 북향: 직달 일사 없음 → 균일 확산광, 서비스 공간

일조 시뮬레이션 결과 (월별)
└── 연간 일조 시간 히트맵 (건물 배치안 별 비교)


**풍환경 분석 (신규 강화)**
지역별 풍향·풍속 DB 자동 적용
├── 연간 주풍향 (빈도 기준)
├── 계절별 주풍향 (여름/겨울 구분)
├── 평균 풍속 (m/s)
└── 돌풍 빈도 (강풍 주의 구간)

풍환경 활용 전략
├── 자연환기 유도 방향 → 개구부 위치 제안
├── 차폐 필요 방향 → 완충 공간 배치 제안
└── 건물 배치에 따른 풍압 예측


**소음 분석 (신규 강화)**

| 소음원 | 예상 소음도 | 허용 기준 | 대응 방안 |
|--------|-----------|---------|----------|
| 전면 도로 | 65~75 dB | 50 dB 이하 (교실) | 방음벽·수림대·이격 |
| 인근 산업시설 | 55~65 dB | 45 dB 이하 (병원) | 건물 배치로 차폐 |
| 항공기 소음 | 50~80 dB | WECPNL 기준 | 고차음 창호 |
| 철도·지하철 | 70~85 dB | 50 dB 이하 | 방진·방음 복합 |

#### 2-3. 영역 3: 인프라 및 교통 접근성 분석

**동선 체계 분석 (신규 강화)**
동선 분리 계획 원칙
├── 보행자 동선
│ ├── 주 출입 보행 동선 (학생·방문객)
│ ├── 서비스 보행 동선 (직원·물류)
│ └── 비상 피난 동선 (소방·대피)
│
├── 차량 동선
│ ├── 일반 차량 (방문·주차)
│ ├── 통학 차량 (승하차 구역)
│ ├── 서비스 차량 (화물·급식)
│ └── 긴급차량 (소방·구급)
│
└── 장애인 동선
├── 주차→출입구 무장애 경로
└── 건물 내부 전 구간 BF 동선

주차 계획 산정
├── 법정 주차 대수 = 연면적 / 용도별 기준 면적
├── 장애인 주차 = 전체 × 2~4% (최소 1대)
├── 전기차 충전기 = 전체 × 5% 이상
└── 지상/지하 주차 비율 검토


**인프라 인입 계획**
인입 방향 분석 (도로변 기준)
├── 상수도: 전면 도로 하부 → 건물 인입
├── 하수도: 경사 방향 고려 → 자연 유하 방향
├── 전기: 전주 또는 지중 인입 → 수변전실 위치
├── 가스: 도로변 공급관 → 기계실 인접 인입
└── 통신: 지중관로 → MDF실 위치

설비실 위치 제안
└── 인입점 최단 거리 + 구조 코어 인접 최적 위치

#### 2-4. 영역 4: 인문·사회적 맥락 분석

**조망 분석 (신규 강화)**
View-out (외부 조망) 분석
├── 주요 조망 요소 파악 (산·강·공원·도시경관)
├── 방위별 조망 가치 등급 (★★★~★)
├── 조망 확보 최적 층수 및 방향 제안
└── 인접 건물에 의한 조망 차폐 분석

View-in (내부 조망) 분석
├── 도로변에서 건물이 보이는 주요 시점 분석
├── 랜드마크 효과 및 정면성 검토
└── 건물 입면 디자인 방향 제안


**CPTED 분석 (신규 강화)**

| CPTED 원칙 | 적용 전략 | 설계 요소 |
|-----------|----------|----------|
| 자연 감시 | 사각지대 최소화 | 창호 위치, 조명 계획 |
| 접근 통제 | 출입 경로 단순화 | 출입문, 펜스, 조경 |
| 영역성 강화 | 공간 소유의식 부여 | 조경, 포장, 색채 |
| 활동 지원 | 안전한 활동 공간 | 운동장, 휴게 공간 |
| 유지 관리 | 시설 관리 용이성 | 내구성 재료, CCTV |

#### 2-5. 영역 5: 종합 분석 및 디자인 전략

**최적 매스 배치 시뮬레이션 (신규 강화)**
AI 기반 배치 대안 생성 (3개 이상)

대안 A: 일조 최우선형
├── 장축 동서 배치, 남향 최대화
├── 교실동 전면 남향 배치
└── 평가: 일조 ★★★, 소음 ★★, 접근성 ★★

대안 B: 동선 효율 최우선형
├── 주출입구 중심 방사형 배치
├── 코어 중앙 집중형
└── 평가: 일조 ★★, 소음 ★★, 접근성 ★★★

대안 C: 소음 차폐 최우선형
├── 소음원 방향 차폐동 배치
├── 정온 공간 내측 배치
└── 평가: 일조 ★★, 소음 ★★★, 접근성 ★★

최적 대안 선정 매트릭스
└── 가중치 적용 종합 점수 산출 → 최적안 추천

### 3. SWOT 분석 고도화

#### 3-1. 기존 SWOT 항목 구조화
강점 (Strengths) - 내부 긍정 요인
├── 대지 규모 및 형태적 강점
├── 법규적 유리 조건
├── 접근성 및 입지적 강점
└── 발주 조건의 기회 요소

약점 (Weaknesses) - 내부 부정 요인
├── 대지 형태·지형 제약
├── 법규적 제한 조건
├── 인프라 연결 제약
└── 예산·일정 제약

기회 (Opportunities) - 외부 긍정 요인
├── 주변 개발 계획 연계
├── 정책적 지원 (보조금, 인증 혜택)
├── 지역사회 수요 증가
└── 기술 혁신 활용 가능성

위협 (Threats) - 외부 부정 요인
├── 주변 환경 변화 (개발, 교통)
├── 법규 변경 가능성
├── 경제적 변동 (물가 상승)
└── 이해관계자 갈등 가능성


#### 3-2. SO·WO·ST·WT 전략 도출 (신규 추가)

| 전략 유형 | 핵심 전략 | 설계 방향 |
|----------|---------|----------|
| SO 전략 (강점×기회) | 강점 활용 기회 극대화 | 입지 강점 살린 랜드마크 설계 |
| WO 전략 (약점×기회) | 약점 보완 기회 활용 | 제약 조건 극복 창의적 배치 |
| ST 전략 (강점×위협) | 강점으로 위협 대응 | 내구성·유연성 확보 설계 |
| WT 전략 (약점×위협) | 약점·위협 동시 최소화 | 리스크 저감 보수적 설계 |

### 4. 인증 배치 체크리스트 (고도화)

#### 4-1. 인증별 배치 단계 체크리스트

**제로에너지건축물 (ZEB)**
배치 단계 체크
├── ☐ 건물 장축 동서 방향 배치 (남향 최대화)
├── ☐ 옥상 태양광 설치 가능 면적 산정 (연면적 × 목표 자립률)
├── ☐ 차양 계획 가능 외벽 면적 확인
├── ☐ 기계실 위치: 신재생에너지 설비 인접 배치
└── ☐ BEMS 중앙 관리실 위치 확보

외피 성능 체크
├── ☐ 외벽 단열 목표값 설정 (U값 기준)
├── ☐ 창면적비 목표 설정 (방위별 차등 적용)
└── ☐ 기밀 성능 목표 설정 (ACH50 기준)


**BF 인증**
외부 동선 체크
├── ☐ 장애인 주차 → 주출입구 단차 없는 경로 확보
├── ☐ 경사로 기울기 1/12 이하 (최우수: 1/18 이하)
├── ☐ 유도 점자 블록 연속 배치 계획
└── ☐ 승하차 구역 캐노피 설치 계획

내부 동선 체크
├── ☐ 주출입구 자동문 계획
├── ☐ 장애인용 엘리베이터 주출입구 30m 이내 배치
├── ☐ 장애인 화장실 각 층 배치 계획
└── ☐ 휠체어 회전 공간 1,500×1,500mm 확보


**G-SEED 인증**
대지 계획 체크
├── ☐ 생태면적률 목표 달성 가능 여부 (용도별 기준)
├── ☐ 자연지반 녹지 최대 확보 계획
├── ☐ 빗물 이용 시설 설치 공간 확보
└── ☐ 자전거 보관소 설치 계획

실내환경 체크
├── ☐ 남향 교실 배치율 (전체 교실의 70% 이상 목표)
├── ☐ 자연채광 가능 창면적 확보
└── ☐ 자연환기 가능 개구부 계획


**CPTED**
배치 단계 체크
├── ☐ 주 출입구: 자연 감시 가능한 위치
├── ☐ 사각지대 발생 구간 없음 확인
├── ☐ CCTV 설치 위치 사전 계획
├── ☐ 외부 조명 배치 계획 (사각지대 없음)
└── ☐ 보안 펜스 및 차단 시설 위치 계획

### 5. 매스 배치 제안 고도화

#### 5-1. 배치 원칙 우선순위 매트릭스

| 배치 원칙 | 가중치 | 평가 기준 |
|----------|--------|---------|

## 🎨 UI 구현 및 프론트엔드 작업 프로세스 (High-Fidelity)

고품질의 전문가용 대지분석 엔지니어링 패널 구축을 위해, 이후 개발되는 모든 Phase C 형태의 패널과 동일한 수준의 시각적 완성도(High-Fidelity)를 적용합니다.

### 8-1. 12-Column Grid 레이아웃 적용
대지분석 결과를 효과적으로 나열하기 위해 12-Column CSS Grid를 기반으로 공간을 분할합니다.
- **좌측/중앙 (col-span-8)**: 5대 영역 분석 아코디언, 디자인 전략 등 핵심 분석 텍스트 및 시각 데이터를 넓게 배치.
- **우측 (col-span-4)**: 결과 요약, 엔지니어링 품질 검증(Seal) 그래픽, SWOT 분석, 배치 제안 등을 세로로 나열하여 정보의 밀도를 높임.
- **하단 (col-span-12)**: 식별된 잠재적 대지 제약(Risk)과 그에 대한 대응 방안(Mitigation)을 다루는 가로형 표(Table) 배치.

### 8-2. 데이터 표시 디자인 시스템
- **색상 팔레트**: 신뢰감을 주는 Emerald / Cyan / Slate 계열을 주조색으로 사용하며 가독성 극대화를 위해 흰 배경(`bg-white`)과 얇은 테두리(`border-slate-200`) 카드를 주로 활용.
- **엔지니어링 데이터 실(Seal)**: 우측 패널 상단에 방패 또는 원형 형태의 대규모 그래픽 뱃지를 배치하여(예: 'Geomatic Analysis Pass' 등), AI 분석이 완료되었음을 시각적으로 증명.
- **리스크 관리 테이블 (Risk & Mitigation)**: 대지분석 시 도출된 주요 위험 요소(지반 단차, 일조권 제한, 도로 폭 불량 등)와 이를 극복하기 위한 설계적 대책을 100% 폭을 차지하는 커스텀 테이블로 렌더링.

### 8-3. 상호작용 및 애니메이션
- Framer Motion을 활용하여 초기 AI 분석 시작 버튼 클릭 후의 로딩 상태(`Loader2`, `animate-pulse`)와 결과 출력 시의 트랜지션(`opacity, y`) 요소 가미.
- 아코디언 메뉴의 매끄러운 높이 조정.
