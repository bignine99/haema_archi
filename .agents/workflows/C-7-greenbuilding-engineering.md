# 친환경 계획
### Green Building Planning | 기본설계 단계

---

## 📌 Description

기본설계 단계의 친환경 계획은 건축물이 환경에 미치는 부정적 영향을 최소화하고
지속 가능한 건축 환경을 구현하기 위한 종합적인 설계 전략을 수립하는 분야입니다.

녹색건축인증(G-SEED), LEED 등 국내외 친환경 인증 취득을 목표로
대지·교통, 에너지, 물, 재료·자원, 실내환경, 유지관리 등
건축물 전 분야에 걸친 친환경 성능 목표를 설정하고
설계에 반영하는 방향을 제시합니다.

---

## 📋 Contents

### 1. 친환경 인증 계획

#### 1-1. 국내외 친환경 인증 체계

| 인증 | 발행처 | 평가 분야 | 특징 |
|------|--------|----------|------|
| 녹색건축인증 (G-SEED) | 국토교통부·환경부 | 대지, 에너지, 재료, 물, 실내환경 | 국내 의무 인증 (공공건물) |
| 에너지효율등급 | 국토교통부 | 에너지 소요량 | 1+++~7등급 |
| 제로에너지건축물 (ZEB) | 국토교통부 | 에너지 자립률 | 1~5등급 |
| LEED | USGBC (미국) | 종합 친환경 성능 | Certified·Silver·Gold·Platinum |
| BREEAM | BRE (영국) | 종합 친환경 성능 | Pass~Outstanding |
| WELL | IWBI (미국) | 건강·웰빙 중심 | Silver·Gold·Platinum |

#### 1-2. G-SEED 인증 평가 항목
G-SEED 평가 체계 (건축물 부문)

토지이용 및 교통
├── 기존 대지의 생태학적 가치
├── 세대당 주차면수 감소
└── 대중교통 근접성

에너지 및 환경오염
├── 에너지 성능 (필수항목)
├── 신재생에너지 이용
└── CO₂ 배출 저감

재료 및 자원
├── 친환경 자재 사용
├── 재활용 자재 사용
└── 자원 순환 계획

물 순환 관리
├── 빗물 이용
├── 중수도 설치
└── 절수형 위생기구

유지관리
├── 건설현장 환경 관리
├── 운영·유지관리 문서화
└── 환경성능 모니터링

생태환경
├── 연계 녹지 확보
├── 자연 지반 녹지율
└── 생태면적률 확보

실내환경
├── 일조 확보
├── 자연환기 성능
├── 음환경 성능
└── 실내공기질 관리


#### 1-3. 인증 목표 등급 설정

| 인증 종류 | 최소 목표 | 권장 목표 | 조건 |
|----------|---------|---------|------|
| G-SEED | 우수 (녹색 2등급) | 최우수 (녹색 1등급) | 공공건물 의무 |
| 에너지효율등급 | 1등급 | 1++ 등급 이상 | |
| ZEB | 5등급 | 3등급 이상 | 신축 공공건물 의무 |
| LEED | Gold | Platinum | 해외 발주처 요구 시 |

### 2. 대지 및 교통 계획

#### 2-1. 대지의 친환경 계획

**기존 대지 생태 가치 보전**
- 기존 수목 최대한 보존 계획
- 표토 보전 및 재활용 계획
- 토양 오염 여부 사전 조사

**열섬현상 저감 계획**
외부 열섬 저감
├── 옥상 녹화 (Roof Garden): 단열+열섬 동시 저감
├── 벽면 녹화 (Green Wall): 복사열 차단
├── 고반사율 포장재 (SRI 29 이상): 주차장·보행로
└── 외부 캐노피·수목 식재: 그늘 확보

내부 열섬 저감
├── 옥상 고반사율 도료 (Cool Roof)
├── 지붕 녹화 적용
└── 차열성 외장재 선정


#### 2-2. 교통 계획

| 항목 | 계획 내용 | 평가 기준 |
|------|----------|----------|
| 대중교통 근접성 | 버스·지하철 정류장 500m 이내 | 보행 거리 기준 |
| 자전거 보관소 | 전체 주차면수의 3% 이상 | 옥내 설치 권장 |
| 전기차 충전기 | 주차면수의 5% 이상 | 급속·완속 구분 |
| 주차 면수 감소 | 법정 기준 대비 20% 이하 | 대중교통 접근성 고려 |
| 친환경 차량 우선 | 충전·주차 우선 공간 배정 | |

### 3. 수자원 관리 계획

#### 3-1. 절수 계획

**절수형 위생기구 선정 기준**

| 기구 종류 | 일반 사용량 | 절수형 기준 | 절감율 |
|----------|-----------|-----------|--------|
| 양변기 | 6~13L/회 | 4.8L 이하/회 | 30~60% |
| 세면기 수전 | 8~12L/min | 5.7L/min 이하 | 40~50% |
| 샤워기 | 9~15L/min | 7.6L/min 이하 | 30~50% |
| 소변기 | 3~5L/회 | 1.9L 이하/회 | 60~70% |
| 무수 소변기 | - | 0L/회 | 100% |

#### 3-2. 빗물 이용 계획
빗물 이용 시스템 구성

집수 → 여과 → 저류조 → 펌핑 → 재이용
│
├── 집수: 옥상면 집수 (집수면적 × 강우량 × 유출계수)
├── 여과: 초기우수 배제 (3mm 배제) + 여과 필터
├── 저류조: 1일 재이용량 × 3~5일 용량
└── 재이용: 조경용수, 청소용수, 화장실 용수

기대 효과
├── 상수도 사용량 20~30% 절감
└── 우수 유출량 저감 (도시 홍수 저감)


#### 3-3. 중수도 계획

| 원수 | 처리 방법 | 재이용 용도 |
|------|----------|-----------|
| 오수 (세면·샤워수) | MBR 처리 | 화장실 세정수 |
| 냉각탑 블로우다운수 | 여과 처리 | 조경용수 |
| 빗물 | 여과·소독 | 조경·청소용수 |

- 중수도 설치 의무 대상
  - 연면적 60,000㎡ 이상 건축물
  - 1일 오수 발생량 1,500㎥ 이상

### 4. 재료 및 자원 계획

#### 4-1. 친환경 자재 선정 기준
친환경 자재 인증 마크 우선 선정
├── 환경마크 (환경부): 전 생애주기 환경영향 평가
├── GR 마크 (산업부): 우수 재활용 제품
├── HB 마크 (건교부): 친환경 건자재
└── EPD (환경성적표지): 탄소 발자국 공개

유해물질 저감 기준
├── VOC (휘발성 유기화합물) 저함유 제품
│ └── 접착제, 페인트, 실란트 등
├── 포름알데히드 방산량: E0 등급 이하
└── 석면 함유 자재 사용 금지


#### 4-2. 재활용 자재 활용 계획

| 자재 종류 | 재활용 비율 목표 | 비고 |
|----------|--------------|------|
| 철근 (재생 철강) | 30% 이상 | 전기로 제강 제품 |
| 콘크리트 (순환골재) | 골재의 10% 이상 | 건설폐기물 재활용 |
| 석고보드 | 재활용 석고 30% 이상 | |
| 단열재 (재활용 유리면) | 일부 적용 | |
| 외장재 (재활용 알루미늄) | 30% 이상 | |

#### 4-3. 탄소 저감 자재 계획

**저탄소 콘크리트 적용**
일반 콘크리트 대비 CO₂ 저감 방법
├── 고로슬래그 혼합 (시멘트 대체 30%)
│ └── CO₂ 배출 40% 저감
├── 플라이애시 혼합 (시멘트 대체 15%)
│ └── CO₂ 배출 25% 저감
└── 탄소포집 콘크리트 (신기술)
└── CO₂ 흡수·저장 기능


#### 4-4. 생애주기평가 (LCA: Life Cycle Assessment)
LCA 평가 범위
A1 (제조단계): 원자재 채취 + 운반 + 제조
A5 (시공단계): 운반 + 시공
B1 (사용단계): 사용 + 유지보수 + 수리 + 교체 + 운영 에너지
C4 (해체단계): 해체 + 운반 + 폐기물 처리
D (순환단계): 재사용·재활용·에너지 회수

평가 지표
├── GWP (지구온난화지수): CO₂ eq.
├── ODP (오존층파괴지수)
├── AP (산성화지수)
└── EP (부영양화지수)

### 5. 생태환경 계획

#### 5-1. 생태면적률 계획
생태면적률 = 생태면적 합계 / 전체 대지면적 × 100

공간 유형별 가중치
├── 자연지반 녹지: 1.0 (최고 가중치)
├── 인공지반 녹지 (토심 90cm 이상): 0.7
├── 인공지반 녹지 (토심 45~90cm): 0.6
├── 옥상 녹화 (토심 20cm 이상): 0.5
├── 벽면 녹화: 0.4
├── 투수성 포장: 0.3
└── 수공간 (연못): 0.7

목표 생태면적률
├── 주거: 0.3 이상
├── 상업·업무: 0.2 이상
└── 학교·공공: 0.4 이상


#### 5-2. 녹화 계획

**옥상 녹화 (Roof Garden)**

| 유형 | 토심 | 식재 종류 | 하중 | 유지관리 |
|------|------|----------|------|---------|
| 저관리형 (Extensive) | 7~20cm | 세덤, 초본류 | 60~200kg/㎡ | 연 1~2회 |
| 중관리형 (Semi-Intensive) | 12~25cm | 초본·관목류 | 120~250kg/㎡ | 연 4~6회 |
| 집약형 (Intensive) | 30cm 이상 | 교목·관목 포함 | 300kg/㎡ 이상 | 정기 관리 |

**벽면 녹화**
- 등반형: 담쟁이, 능소화 등 자연 등반
- 지지대형: 격자·와이어 설치 후 식재
- 유닛형: 플랜터 모듈 설치
- 관수 자동화: 점적 관수 시스템 적용

#### 5-3. 외부 공간 생태 계획
- **비오톱(Biotop)** 조성: 소생물 서식 공간 확보
- **우수 침투 시설**: 침투 트렌치, 투수 포장, 침투 저류지
- **바람길 확보**: 건물 배치 계획과 연계한 통풍 계획
- **자생 식물** 우선 식재: 유지관리 비용 절감 및 생태 다양성 확보

### 6. 실내 환경 계획

#### 6-1. 실내공기질 관리 계획

**VOC 저감 계획**
오염원 제어
├── 저VOC 도료·접착제·실란트 선정
├── 포름알데히드 방산 E0 등급 이하 자재 선정
└── 자재 반입 전 VOC 함량 검증

환기 계획 연계
├── 시공 후 Flush-Out (집중 환기)
│ └── 입주 전 14일 이상 집중 환기 실시
└── CO₂ 연동 외기 도입 제어


**실내공기질 기준 (다중이용시설)**

| 오염물질 | 기준값 | 비고 |
|---------|--------|------|
| 미세먼지 (PM10) | 100 μg/㎥ 이하 | |
| 초미세먼지 (PM2.5) | 50 μg/㎥ 이하 | |
| CO₂ | 1,000 ppm 이하 | |
| 포름알데히드 | 100 μg/㎥ 이하 | |
| VOC | 500 μg/㎥ 이하 | |
| 라돈 | 148 Bq/㎥ 이하 | 1층 이하 공간 |

#### 6-2. 자연채광 계획
자연채광 성능 지표
├── DA (Daylight Autonomy): 연간 조도 목표 달성 시간 비율
│ 목표: 사무실 300lx 기준, DA 50% 이상
├── UDI (Useful Daylight Illuminance): 100~2,000lx 범위 비율
│ 목표: UDI 75% 이상
└── ASE (Annual Sunlight Exposure): 과도 일사 방지
기준: 250lx 이상 250시간 초과 면적 10% 이하

자연채광 확보 방법
├── 창면적비: 외벽 면적의 30~50%
├── 광선반(Light Shelf): 직달 일사 반사·확산
├── 고측창(Clerestory): 깊은 실내 채광
└── 천창(Skylight): 코어부 자연채광


#### 6-3. 열쾌적성 계획

**PMV (예상평균쾌적지수) 기준**

| PMV 값 | 열쾌적 상태 | 목표 범위 |
|--------|-----------|----------|
| +3 | 매우 더움 | |
| +2 | 더움 | |
| +1 | 약간 더움 | |
| 0 | 쾌적 | ▶ 목표: -0.5 ~ +0.5 |
| -1 | 약간 추움 | |
| -2 | 추움 | |
| -3 | 매우 추움 | |

- **개인 제어 가능성** 확보: 재실자 개별 온도·환기 조절 가능 시스템
- **복사 열환경**: 바닥 복사냉난방 적용 검토
- **외피 결로 방지**: 열교 차단 설계, 단열 연속성 확보

## 🔄 Implementation Workflow
STEP 1. 친환경 목표 설정
├── 발주처 친환경 요구사항 수렴
├── 의무 인증 대상 여부 확인
├── 인증 목표 등급 설정
└── 친환경 예산 범위 확인
 │
  ▼
STEP 2. 대지·교통 분석
├── 대지 생태 현황 조사
├── 대중교통 접근성 분석
├── 기존 수목·표토 보전 계획
└── 열섬현상 저감 계획 수립
 │
  ▼
STEP 3. 친환경 설계 전략 수립
├── 에너지 (에너지 SKILL 연계)
├── 수자원 관리 계획 수립
├── 재료·자원 계획 수립
├── 생태환경 계획 수립
└── 실내환경 계획 수립
 │
  ▼
STEP 4. 친환경 시뮬레이션 수행
├── 자연채광 분석 (Radiance·Ladybug)
├── 자연환기 분석 (CFD)
├── 생태면적률 산정
└── LCA 탄소 배출 분석
 │
  ▼
STEP 5. 인증 사전 검토
├── G-SEED 항목별 점수 예비 산출
├── 인증 취약 항목 보완 계획
└── 인증 대행기관 협의
 │
  ▼
STEP 6. 도서 작성 및 승인
├── 친환경 기본설계 설명서 작성
├── 친환경 인증 사전 검토서 작성
├── 생태면적률 산정서 작성
└── 발주처 보고 및 승인

## 8. UI 구현 및 프론트엔드 작업 프로세스 (Implementation Workflow)

**본 친환경 지식을 `GreenBuildingPanel.tsx` UI로 구현할 때 참조해야 할 가이드라인입니다. (김해제2특수학교 메타데이터 반영)**

### 8.1. 레이아웃 구조 (Grid Layout - Col 12)
이 화면은 `App.tsx`의 "친환경" 탭 선택 시 노출됩니다. 다른 엔지니어링 패널과 동일한 UI 프레임을 유지합니다.

1. **Header 영역:** `친환경 건축 및 치유 생태계 조성` 타이틀 및 요약. 아이콘은 `Leaf`, `Sun`, `Droplet` 활용.
2. **Section 1: 실내 공기질 및 빛환경 치유 (Col 1-12)**
    *   **(좌측단 7/12):** 특수학교 호흡기/면역 취약 학생들을 위한 실내공기질(IAQ) 지표. 미세먼지(PM2.5) 연동 자동 환기 시스템 및 Flush-out 계획 시각화 (VOC, 포름알데히드 E0 등급 강제 명기).
    *   **(우측단 5/12):** 정서 안정(빛환경 치유)을 위한 자연채광(Daylight Autonomy) 분석. 심리치료실 간접 채광 및 다목적 체육관 옥상 천창(Skylight) 글레어 방어 전략 표기.
3. **Section 2: 수자원 밸런스 및 생태(G-SEED) 인증 (Col 1-12)**
    *   초대형 수중운동실 배치로 폭증하는 물 소비량을 억제하기 위해, 우수저류조+중수도 연동을 통한 절수형 시스템(Water Balance) 도입 다이어그램.
    *   공공 신축 필수 취득 기준(G-SEED 최우수(그린 1등급)) 획득을 위한 분야별 타겟팅 점수 현황.
4. **Section 3: 생태환경/치유공간 조성 리스크 관리 (Col 1-12)**
    *   화면 최하단 테이블. "옥상 휠체어 텃밭 토심 가중으로 인한 하중 초과", "친환경 무독성 자재 수급 지연", "입주 전 Flush-out 강행에 따른 동절기 비용 리스크" 심각도 표기 및 방어 기제 표기.
