# 🗺️ 페이지 ↔ 스킬 매핑 노티스 (Page-Skill Mapping Notice)

이 문서는 **"AI가 특정 프론트엔드 UI 페이지(대시보드 패널)를 개발·수정할 때, 반드시 어떤 스킬(Skill) 파일을 사전에 읽고 참조해야 하는지"**를 정의하는 중앙 관제 라우터(Router) 역할을 합니다.

## 🎯 사용 지침 (For AI)
1. 프론트엔드/백엔드 컴포넌트 수정 및 생성 요청이 들어오면 **가장 먼저 이 문서를 확인**합니다.
2. 타겟 컴포넌트에 매핑된 `[적용 스킬 파일]`을 `view_file` 툴로 완독하여, 해당 도메인의 필수 엔지니어링 제한치 판정 기준과 **UI 렌더링 작업 프로세스(하단부)**를 완벽하게 인지한 후 코딩에 돌입합니다.
